# A 场景模块：主地图集成

当前工作基于 C 的 `codex/panorama-map-framework`（`728cbd3`）。从原项目首页“开启征程 → 立即进入”进入同一主应用；正式出口为 `LongMarchSceneV2` 与 `ImmersiveExperienceRenderer`，旧 `LongMarchScene` 出口继续兼容。

```sh
npm ci
npm run dev
```

## 本轮入口与能力

- 主地图共用 C 的墨卡托坐标转换、八个现代区域 DEM、河道、岩石材质、相机飞行。旋转、缩放、全程／俯瞰与区域选择直接位于主页面。
- 地图只消费 C 传入的阶段投影；阶段切换替换部队与路线图层。已知点位采用近景代表性白模／远景标记；区域只画边界，路线不推算当前军队位置。未知位置保持隐藏。
- 八个区域均可在同一主应用进入人物与地形观察空间，含三类观察点、阅读和思考反馈；泸定沿用桥谷，其余七区使用区域场景。退出恢复地图与区域选择，自由观察入口不写正式历史体验完成记录。
- 八区已接入 MiniMax 情境短片：点选先播带原生声音的影片，结束后淡入较远三维视角，再自由环顾、缩放或近看。播放器支持暂停、音量、重看、受限自动播放入口与错误回退；主地图封面来自实际选定影片。当前成片、构建与浏览器简查范围见 [八区体验与交接记录](integration/REGION_EXPERIENCE_REVIEW.md)。
- `ImmersiveExperienceRenderer` 接 C1 的 runId、播放命令、段落、互动提示、终段、退出及书签接口。泸定桥保留桥谷渲染，另外五个正式专题接入区域渲染适配；完成判断仍由 C 管理。渲染适配不替代 B 的审核内容与 C 的正式体验联调。

## 分工与待联调

地图时钟、历史阶段、史料发布及完成判定继续由 C/B 管理。历史路线与部队位置仅消费宿主传入的审核发布数据，未知位置不补全。当前八区艺术场景与影片没有添加正式历史坐标、时间、具体人物言行或审核记录。

C 的纯渲染文件与现代地理素材迁入 `atlas/`，原 `src/app/panorama` 文件保留兼容转出口，避免生产场景反向依赖开发工作台。这个跨目录提取需在集成 PR 中由 C 审阅；没有改动 App、时间轴或共享契约。

八区自由观察已集成；正式体验仍需宿主内容、调度与审核数据共同联调。本轮为内部集成迭代，用户已授权准备同步 GitHub，不作为历史数据已发布或正式体验全部完成的证明。

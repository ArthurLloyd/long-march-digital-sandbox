# A 场景模块：主地图集成

当前工作基于 C 的 `codex/panorama-map-framework`（`728cbd3`）。从原项目首页“开启征程 → 立即进入”进入同一主应用；正式出口为 `LongMarchSceneV2` 与 `ImmersiveExperienceRenderer`，旧 `LongMarchScene` 出口继续兼容。

```sh
npm ci
npm run dev
```

## 本轮入口与能力

- 主地图共用 C 的墨卡托坐标转换、八个现代区域 DEM、河道、岩石材质、相机飞行。旋转、缩放、全程／俯瞰与区域选择直接位于主页面。
- 地图只消费 C 传入的阶段投影；阶段切换替换部队与路线图层。已知点位采用近景代表性白模／远景标记；区域只画边界，路线不推算当前军队位置。未知位置保持隐藏。
- 选择“泸定河谷”→“走近桥谷 · 结构观察”进入同页三维空间，包含已有峡谷、桥索、动态水面及原创 18 人白模编队；退出恢复地图与区域选择。该观察入口不写历史体验完成记录。
- `ImmersiveExperienceRenderer` 接 C1 的 runId、播放命令、段落、互动提示、终段、退出及书签接口。泸定桥使用真实渲染后的回调；完成判断仍由 C 管理。其他体验返回 `media_unavailable`，交回 C 的图文回退。

## 分工与待联调

地图时钟、历史阶段、史料发布及完成判定继续由 C/B 管理。当前 B 候选集中 0 条路线、9 个隐藏态势快照、地点坐标为空；因此正式页面仍显示核验状态。本轮没有添加历史坐标、时间、人物身份或审核记录，也没有开展视频制作。

C 的纯渲染文件与现代地理素材迁入 `atlas/`，原 `src/app/panorama` 文件保留兼容转出口，避免生产场景反向依赖开发工作台。这个跨目录提取需在集成 PR 中由 C 审阅；没有改动 App、时间轴或共享契约。

雪山、遵义的独立沉浸场景尚未实现；八个区域的现代地形观察已接入。公开发布前还需合并 C 的内容发布隔离工作。本轮为内部集成迭代，不作为历史数据已发布或最终验收的证明。

1. 总图采用 C 的现代 DEM、OSM 水系和 CC0 岩石材质；地势增强是视觉处理，UI 保留现代地理及非历史地貌复原说明。
2. 军队层只读取 C 的当前阶段输入。确知点位才出现代表性模型；远近切换带迟滞，避免缩放时闪烁。区域不生成中心点，路线不推算当前军队位置，缺失或越界顶点不跨段连线。
3. 同一主页面内打开桥谷结构观察对话框。背景地图暂停绘制，关闭后恢复原视角。近看编队使用旧 A 的原创白模，18 个实例不表示史实人数、服装或桥面状态。

## 本轮采用的开源交互参考

沿用模块已有 20 项案例研究，再结合 Three.js 官方示例核对实现方式：

- [LOD](https://threejs.org/examples/webgl_lod.html)：远处保持可读符号、近处展示模型。本实现增加双阈值，避免临界缩放闪烁。
- [动态实例](https://threejs.org/examples/webgl_instancing_dynamic.html)：编队使用实例几何降低重复绘制开销，保留原可编辑白模的变换。
- [骨骼动画混合](https://threejs.org/examples/webgl_animation_skinning_blending.html)：参考动作与状态分离；本轮继续使用原创程序白模，没有把官方士兵当成长征军装。
- [天空着色](https://threejs.org/examples/webgl_shaders_sky.html)：参考天空、太阳与空间层次；保留已有原创桥谷光雾、水面与材质。

版式融入原主应用的青绿、岩灰、金色与书法题字。入口采用简短动作描述，将地理来源与艺术表达说明放在画面边缘，避免遮挡地图及时间轴。没有新增依赖或下载第三方模型。

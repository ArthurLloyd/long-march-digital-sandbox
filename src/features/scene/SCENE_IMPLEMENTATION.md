# A0 主场景：接入与验证边界

本次把 `LongMarchScene` 的 DOM 占位替换为真实 Three.js/WebGL 2 场景；公共命名导出与 v1 props 不变。仅使用已锁定的 `three`、`lucide-react` 与 React，不新增依赖，不修改应用壳、全局样式或正式数据。

## 空数据与美术

空数据展示原创程序化「火种」展陈：三道铜金曲面、发光核心、深色圆形展台和克制的浮尘。它不是地形、建筑复原、行军路线或历史影像；画面持续标注「艺术化表现 / 非史实地图」。没有借艺术背景补造坐标、人物言行或历史场景。无外部图像、模型、音频、贴图和视频请求。

几何、布局及模块代码由本次开发生成；不复制参考网站资源。所依赖 Three.js（含 OrbitControls）遵循依赖包自带 MIT 许可，React 与 lucide-react 的许可沿用锁定依赖。字体与原应用素材由 C 的现有来源记录负责。本次不重新声明其权利。

## 发布数据接入

- `events/routes` 仍只接受 C 从唯一发布入口取得的数据。主场景额外拒绝非 published/reviewed 记录、未知事件坐标、非法坐标及不符合公共 schema 的路线，但不替代来源关联和双人人工复核。
- WGS84 `[longitude, latitude]` 投到以输入包围框中心为原点的局部等距圆柱显示平面：`x = Δlongitude × cos(centerLatitude) × scale`，`z = −Δlatitude × scale`。相邻日期变更线做经度展开；没有高程，y 是图形层次偏移，不是海拔。
- 这是一种便于辨读的坐标投影。它不声称测量精度、三维地形真实性或地图合规认证；大范围、高纬度呈现会产生投影变形。比例按坐标范围适应展台，未展示测距尺。
- documented_geometry + solid 直接逐段连接原始相邻坐标，不平滑或插点。进度只高亮已经完整经过的原始线段；未到完整段边界时不创建中间坐标。
- confirmed_locations + points 保持独立点，不连线。schematic + dashed 使用虚线，并持续显示「宏观示意，非真实行军路线」。hidden/insufficient 不绘制。
- 事件选择通过原始 eventId 回调 C；`activeEventId` 驱动节点高亮与镜头。未知坐标事件仍由 C 的时间轴和文字面板处理，场景不伪造一个位置。

## 操作、资源与回退

左键拖动环顾；右键或双指拖动平移；滚轮/双指缩放；相机按钮支持总览、俯瞰、放大、缩小。画布可键盘聚焦，方向键旋转、Shift + 方向键平移、`+/-` 缩放、Home 复位。平移目标限制在展台附近（艺术视图 x/z ±4，坐标视图 ±9，y 0–5），相机与目标同步位移，保持当前视角；旋转、缩放范围也受约束，避免拖出不可恢复范围。发布节点另有原生可展开列表，键盘用户可直接选择。

首次成功渲染后才触发 ready；无 WebGL 2 回调 webgl_unavailable，渲染异常或 context lost 回调 render_failed，由 C 的错误容器处理重试。当前没有异步外部素材，因此不存在伪造的素材加载成功状态。

低画质限制 DPR 为 1、关闭浮尘、以约 30 FPS 上限提交动画帧；常规 DPR 上限 1.75。窄屏/高 DPR 默认轻量，可手动切换；持续慢帧也会自动降级。减少动态模式停止雕塑动画，镜头切换直接定位；静态数据与静止模式只在相机、数据或尺寸变化时重绘。页面隐藏时不渲染。

组件卸载会取消 RAF、断开 ResizeObserver、移除指针/键盘/可见性/系统动态偏好监听、销毁 OrbitControls、释放几何和材质、销毁 renderer 并丢弃 WebGL context。环形刻度使用 InstancedMesh，避免逐刻度提交 draw call。

## 测试

`scene-data.test.ts` 覆盖空态、未知/非法坐标、draft、hidden、独立点、虚线精度、投影方向、跨日期变更线和完整线段进度。`scene-renderer.test.ts` 使用可控 GPU mock 覆盖无 WebGL、首帧 ready、context lost、渲染失败、释放 GPU 对象与停止后续帧。Mock 不等于真机 GPU 验收；实际浏览器画面、窄屏、触摸和帧率由本次交付记录另列。

## 后续接口

本模块未引入未合并的 v2 contracts。地图阶段/部队态势与沉浸体验播放器按 C0 合并后的正式类型再接入；当前 A0 的隔离桥体小样由 `prototype/` 单独承载，不从生产 `index.ts` 导入。历史内容和真实地形只有在资料、授权与复核完成后接入。

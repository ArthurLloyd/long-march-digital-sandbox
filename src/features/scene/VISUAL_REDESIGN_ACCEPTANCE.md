# R2：视觉、文案与交互实际验收

日期：2026-11-01。本轮在 A0 的 `f2e5b656` 上升级；主线数据、公共契约与 C 的应用壳未变。本报告记录本轮结果，首轮 A0 报告保留作版本记录，不用首轮帧率代表新版。

## 已改变的体验

- 章节呈现为《渡 · 山河之间》：自托管书法题字、朱红印记、旧金细线和低密度 HUD。主操作使用“启程、驻足观察、回望来路、继续前行”，不再要求用户阅读并确认工程免责声明。
- 峡谷从简单坡面改为连续不对称的侵蚀岩壁、岩脊、远山和岸石；程序石材/木材/锈铁纹理，桥板磨损、链环、吊杆、铆钉与局部红色飘带。冷色远雾、暖色主光、桥面补光、天空/日晕、水面高光与轻量 bloom 共同组织空间。
- 三种预设视角与约1.25秒平滑过渡，主动输入可中断；拖动、键盘、缩放或切换视角时暂停叙事，继续时接回导览。恢复过程的目标随叙事时钟更新，避免转场结束跳切。
- 桥索、两岸用世界坐标投影到屏幕；被任务卡遮挡时以细引线连回原锚点，出视野隐藏。文字入口为等效操作，选中/已观察状态与视角选中同步。
- 40秒停点改为真正的回望机位操作。观察与回望仍需主动完成，不能靠计时、暂停按钮或结束页绕过。
- 自由观景不推进时钟；取景隐藏并禁用 HUD，提供 Esc 与触屏返回；设置使用原生 dialog；任务卡可收起。环境声默认关闭，由用户点击后运行本地合成函数，未引入录音或外部服务。
- 只有一处“艺术演绎”入口，细节在按需说明中。主展台也将原来的常驻工程备注收为艺术演绎说明；正式示意路线仍保留必要的精度标识。

## 实际浏览器验证

本机 Apple M4，Chrome 156，WebGL 2 / ANGLE Metal。1440×900 桌面；390×844、360×640 为同一台电脑的手机视口/触摸模拟，不能当作手机 GPU、温控或真实双指验收。

| 项目               | 实际结果                                                                                                                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 新版桌面精细档     | 1440×900：约30 FPS，呈现帧间隔 p95约34.2ms，81 draw calls，346,406 triangles，45 geometries，18 textures；包含后期 passes。约30FPS为主动限帧，p95不是GPU纯耗时。                     |
| 新版手机视口轻量档 | 390×844：约29.8 FPS，p95约34.4ms，28 draw calls，200,702 triangles，28 geometries，3 textures；关闭阴影/bloom和部分环境。                                                            |
| 必需互动           | 减少动态逐段走完16/40/60；只观察桥索不能继续，两项齐全才可继续；40秒未回望不可继续；最终出现完成页。正常播放也在16秒准确停住，未自动越过。                                           |
| 热点与镜头         | 桥索/两岸实际点击聚焦；桌面被任务卡挡住的热点已通过引线避让。选择桥索后预设视角选中值为1。出视野的热点隐藏，列表仍可完成。                                                           |
| 自由观景           | 时间保持0，隐藏叙事进度条，视角/观察说明可以操作。                                                                                                                                   |
| 鼠标和键盘         | 实际鼠标拖动与 canvas ArrowRight 均将 playing 改为 paused；继续后时间重新推进。                                                                                                      |
| 设置               | 打开后聚焦关闭按钮，Shift+Tab循环至末端；Esc关闭并归还触发按钮。打开时暂停，关闭后保持暂停。                                                                                         |
| 取景               | HUD inert，Esc退出并归还焦点；停点进度保留。正常playing进入取景后暂停，退出恢复playing。                                                                                             |
| 手机短屏           | 两种尺寸无页面横向/纵向溢出。360短屏40秒继续按钮和60秒返回展馆曾被裁切/覆盖，已修复并重新以按钮中心命中与实际点击通过；任务卡可收起。                                                |
| 环境声             | 默认0个AudioContext、aria-pressed=false；用户点击后1个running上下文（48000Hz），反复开关沿用同一实例。通过测试导航脚本只读捕获原生构造器实例，没有修改源码。未对音色做主观听感验收。 |

| 控制台             | 最终桌面、手机检查无error/warn；新字体加载成功。                                                                                                                                     |

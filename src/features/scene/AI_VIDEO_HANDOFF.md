# A 模块 AI 影像补充制作交接

日期：2026-11-01。状态：**制作 brief／待审核方案，尚未生成素材或接入播放器。**

本轮没有真实 AI 视频文件，没有调用视频生成服务，没有新增模型、API、播放器或服务依赖。下列文件名、镜头时长和接入位置都是未来制作约定，不表示文件已经存在、权利已经确认或 v2 已经集成。

## 作用与现有工程边界

AI 影像补充远景气氛、环境细节和收束画面。A0 现有的实时地图操作、桥谷相机、桥体观察、暂停／继续／重置与互动停顿仍由代码完成；**不能用预录视频替代 A0 的实际交互，也不能用视频播放完毕认定必要互动已完成。**

当前隔离原型约一分钟，在 16 秒与 40 秒处进入工程观察／确认停顿，定义见 `prototype/sequence.ts`。这三个拟制镜头不插入当前时序、不占用或跳过两个停顿，不更改主场景 v1 接口。未来若采用影像，由 B 与 C 重新确认段落编排及总时长；三个镜头各 8 秒、合计 24 秒，不意味着正式体验仍然恰好一分钟。

所有画面都是原创河谷与桥体工程概念，**不对应某座历史桥梁、具体河流、真实地形或真实战役现场**。不出现具体战斗、伤亡、人物讲话、家书、电报或行动过程；不借 AI 画面补全历史地图、坐标、行军路径或桥梁结构史实。

## 三个短镜头

### 镜头 01：远景——雾中的结构轮廓

拟交付名：`concept-valley-wide-v01.mp4`。时长 8 秒。

**目的：** 在进入实时桥体观察前，建立环境尺度与空间方向。未来可作为 B 的 `context` 段落候选，采用 `video`；是否采用、对应正式段落 ID 与位置由 B/C 审核。

**画面 brief：** 原创非地理河谷概念。两侧岩壁形成不对称框景，一座没有地标特征的简化悬索步桥位于中景，桥面从左下偏中的位置延伸向右上远端。灰青河水位于下方，远景由两层淡灰山脊与薄雾构成。远端雾后有一处克制暖光，桥体保持清楚暗色剪影。不得出现人、旗帜、文字、地名、地标建筑或战斗痕迹。

**镜头安排：** 0–1 秒稳定建立构图；1–6.5 秒缓慢向前推进，桥体在画面中的尺寸只增加约 10%；6.5–8 秒逐渐稳定。镜头不穿越桥面、不改变视轴方向、不展示虚构道路网络。

**代码接续：** A 用实时相机书签匹配最后一帧的大致构图；视频退场后，用户仍能真实旋转、缩放、观察桥体。视频末帧不冒充可交互 WebGL 画面。

**静态替代说明：** “概念河谷中，一座简化桥体连接两侧岩壁；画面用于展示空间层次，不代表真实历史地点。”

### 镜头 02：环境——水、岩与桥索

拟交付名：`concept-valley-atmosphere-v01.mp4`。时长 8 秒。

**目的：** 补充实时小样不必高成本模拟的水雾和材质细节。未来可作为 `observation` 或 `process` 段落的 `mixed` 候选。`mixed` 仅表示该段有视频与实时内容；不表示在视频上放热点就完成了实际桥体交互。

**画面 brief：** 使用与镜头 01 相同桥体、流向、色彩和光线。取侧下方中近景，一条稳定桥索在画面上部形成斜线，木板与连接件保持明确接触，远处岩壁适度虚化。画面下方仅有缓慢流动的灰青水纹和少量白色水雾。不拍人物、不拍过桥行为，不出现人为爆破、火光、弹孔、血迹或倒塌。

**镜头安排：** 0–1 秒静止；1–7 秒平缓向右横移，移动量不超过画面宽度约 8%；7–8 秒稳定。水流连续、低频变化，桥体结构和数量不随帧改变。

**代码接续：** 两个必要互动仍由 B 定义并由 C 调度，A 仅报告互动 cue；到 cue 必须暂停视频和实时相机运动。用户的观察／回答／解释确认都发生在实际代码界面，不能烘焙成影片中的假按钮或假点击。

**静态替代说明：** “桥索与木板的连接、下方水面及岩壁共同构成工程概念细节；这些细节没有历史结构考证含义。”

### 镜头 03：收束——留一束微光

拟交付名：`concept-valley-closing-v01.mp4`。时长 8 秒。

**目的：** 完成互动后收束视觉节奏，让用户回到可操作空间。未来可作为 `conclusion` 的视频候选；它是否为 terminal 段落只能由 B/C 的 manifest 决定，不能由文件名或片尾动画自行决定。

**画面 brief：** 同一原创河谷、同一桥体，从中远景轻微抬升，看到桥体与两岸的整体关系。前景阴影逐渐沉静，远端暖光穿过雾层，但不出现“胜利”“到达某地”等结论文字。画面只保留桥、山、水、雾和微光，不生成旗帜、真实人物、仪式或历史结果。

**镜头安排：** 0–1 秒稳定；1–6.5 秒缓慢抬升约一个小视角，地平线不倾斜，不绕桥旋转；6.5–8 秒停留在安静的完整构图。不在源视频中硬切黑屏，让 C 控制退出和衔接。

**代码接续：** A 仅在当前有效 `runId / segmentId` 到达边界时报告 `onTerminalReached`（且该段被 manifest 指定为末段）；C 决定后续状态。旧 run 的视频结束事件、重播或失败恢复不能重复触发完成写入。回到地图后使用 C 提供的相机书签，恢复由代码控制的真实场景。

**静态替代说明：** “镜头回到河谷整体，暖光留在雾后；这是艺术气氛收束，不表达新增历史事实。”

## 每个镜头必须交什么

以下是交付清单，不是已生成文件目录：

1. **视频：** 1080p 网页交付版；如已约定则附 720p 轻量版。文件名、实际时长、帧率、尺寸、编码、字节数与 SHA-256 写入素材记录。
2. **静帧：** 首帧、末帧及一张清楚的中间代表帧，PNG 母图与 WebP 网页版。保持与最终视频相同裁切和标注，供海报、减少动态与等价图文使用。
3. **字幕：** UTF-8 WebVTT。无旁白时只含真实的画面说明，不编写历史口述或伪造原话；全程 AI 标注另由画面和播放器持续提供，不依赖字幕开关。说明文字由 B 审核后再进入正式体验。
4. **生成记录：** 原始提示词、负面约束、实际生成工具与模型版本、生成日期、操作者、参数、支持时记录的 seed／任务 ID、参考图原始文件及权利、候选版本、采用理由、失败重试记录。没有提供的字段写“未提供”，不编造。
5. **加工记录：** 任何裁切、调色、稳定、补帧、叠字、转码、混剪及其版本；记录输入与输出文件校验值。出现需要修补的结构错误时保留原始候选，不把修复过程隐去。
6. **权利与审核：** 素材创作者、来源、生成工具适用条款记录、参考图权利、署名要求与发布限制。B/C 确认后维护实际审核记录；A 或 AI 不预签“审核通过”。

镜头之间若有桥形漂移、镜头穿模、水流反转、无意生成文字／人物／地标、过曝闪烁或动态不适，退回制作，不用解说词掩盖画面错误。

## 播放与降级验收

- 在未来 C0 合入与素材实际交付之后，才验证 `video / mixed` 接入；当前 A0 不宣称支持了未实现的正式播放器。
- 暂停时视频、相机及时间统一停止；恢复从同一段落继续；重置、新 run 和退出能释放旧事件与播放状态。
- `muted` 始终生效。即使本批次无音轨，也不能假定以后素材永远无声。
- 减少动态模式优先静帧及等价说明，仍保留 B/C 要求的真实互动和解释确认；视频失败不能自动跳过互动。
- 加载／解码失败使用 v2 的 `media_unavailable` 或按实际原因报告 `asset_load_failed`，提供 C 可处理的错误信息；不假报 ready 或 terminal。
- 低画质使用经确认的轻量资源；切换质量不改变段落身份、回答状态或完成次数。
- 桌面、窄屏、键盘、字幕、标注可读性和实际播放性能分别验收。MP4 能打开不代表整个体验通过验收。

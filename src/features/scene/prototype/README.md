# A0：河谷与桥，隔离沉浸工程小样

本页是 A0 工程入口，不是正式泸定桥体验。主应用及 `scene/index.ts` 不导入本目录，不写入 dataset 或 localStorage；默认生产构建仅包含根 index.html，因此不会输出本小样。入口另有 `import.meta.env.DEV` 保护。

在仓库执行 `npm ci`、`npm run dev` 后，打开终端 Local 地址下的 `/src/features/scene/prototype/index.html`。端口以终端实际输出为准。

## 已实现行为

- 原创程序化河谷、桥体、桥索、桥面、水与冷暖光。所有几何单位都是虚构局部美术单位，无地理坐标、DEM、历史地貌、真实战斗细节或人物对白。
- 三段预设镜头，约 60 秒演绎预算；画布拖动环顾、滚轮缩放、方向键调整、Home/复位；三个原生按钮提供相同的观察入口。
- 16 秒停在两项观察，分别打开“桥体”“两岸”说明后，必须主动继续；40 秒停在说明确认，确认后再次主动继续。两个停点演示机制，不冒充正式 ld-01/ld-02 历史互动。
- 暂停只影响 playing/paused；互动时不能用暂停按钮绕过门槛。大时间步被截到停点，不跨过互动。到终点只显示工程结束，不写历史完成记录。
- 进入后台自动暂停，回来不会补算时间；低动态用户以“下一段”逐步观察，同样保留两个停点。静音文字引导，无伪造音轨和无效音量开关。
- 窄屏默认低画质；标准像素比上限 1.5，低档为 1 且关闭阴影。帧提交上限约 30 FPS。运行信息显示实际呈现帧间隔 p95、FPS、draw calls、三角形、几何/纹理数量，不把限帧间隔称 GPU 纯渲染耗时。
- 退出不判完成；重播完全重建；上下文丢失/初始化失败给出错误入口；pagehide/HMR 释放 RAF、控件、监听、ResizeObserver、几何、材质、阴影与 renderer。

## 美术、素材与验证边界

没有下载或复制参考网站的模型/照片/视频。几何与 GLSL 为本次原创实现；依赖沿用项目锁定的 Three.js 与 Fontsource 字体，许可随依赖及 public/licenses 保存。参考取舍见上一层 `design-references.md`，AI 视频建议见 `AI_VIDEO_HANDOFF.md`。

此小样不提供历史证据、不签署人工核验、不改变 C 的首页与全局状态。正式泸定桥的片段排序题、剧本和资料由 B 提供并审核；C0/C1 接入最终 props、runId、完成验证与等价流程后，再提交历史闭环。

程序化地形虽然能演示空间与光照，不是 A1 有来源的 DEM 地形。手机窄视口模拟也不等于真实手机 GPU、双指触摸与温控验收。实际本轮检查记录见上一层 A0 验收报告。

# 渡 · 山河之间

A0 的独立沉浸场景，第二轮视觉与交互改版。通过虚构的峡谷与悬桥组织一段约一分钟的空间体验；保持在开发入口，未接入正式历史体验、数据或完成记录。

## 运行

```sh
npm ci
npm run dev
```

打开终端 Local 地址下的 `/src/features/scene/prototype/index.html`。主应用与 scene/index.ts 不导入本页；默认生产构建不输出此 HTML，入口保留 DEV 保护。

## 一段完整体验

- **启程**：从峡谷远景平滑走近桥畔。拖动、方向键、滚轮或选择预设视角会暂停叙事；点击继续后平滑回到引导镜头。
- **驻足观察**：16 秒停下。桥索与两岸各有世界坐标锚点和可用键盘操作的文字入口；选择后聚焦并给出说明。两个目标均观察后，主动继续。
- **驻足回望**：40 秒停下。选择“回望来路”切换第三视角，再主动继续。这里是实际观察动作，不再要求勾选工程说明。
- **抵达**：60 秒呈现三个阶段印记及本轮观察结果。可重新体验或返回展馆；不向正式历史系统写完成状态。
- **自由观景**：不启动叙事时钟，使用三种视角、环顾和观察点浏览。
- **取景**：隐藏并禁用 HUD，暂停正在进行的叙事；保留退出按钮，Esc 返回，随后按进入前的状态恢复。不是截图导出功能。
- **设置与声音**：环境声默认关闭，只在用户点击后创建 AudioContext；音量可调，后台静音，退出关闭。图形精细/轻量可切换；控制说明和内容说明按需打开。

原生 dialog 提供设置的焦点约束、Esc 与焦点归还。手机任务卡可收起；热点受面板遮挡时以引线连接原始锚点，离开视野则隐藏，文字入口始终可用。减少动态时不自动运镜/推进，以“下一程”通过相同任务。

## 视觉实现

连续但不对称的侵蚀峡谷、大岩脊、分层远山、草丛与岸石；原创程序石材/旧木/锈铁纹理；磨损桥板、链环、吊杆和铆钉；定向水纹、Fresnel 高光与岸边泡沫；天空、云、薄雾、侧逆光和克制光晕。精细档使用 Three 自带 RenderPass → UnrealBloomPass → OutputPass；轻量档关闭 bloom、阴影和部分环境细节，保留主要空间与互动。未新增依赖。

相机过渡约1.25秒，可手动中断；受局部艺术地形范围约束。ResizeObserver 只标记尺寸变化，由渲染帧合并更新。退出、HMR、pagehide 释放监听、RAF、相机控制、几何/材质/纹理、后期渲染目标与音频。性能面板报告实际呈现帧间隔，限帧间隔不是 GPU 纯耗时。

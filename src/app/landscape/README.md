# C：正式展馆的现代全景地图

`ExhibitionPanorama` 接受既有 `LongMarchSceneV2Props`；它消费 App 已验证、已发布且按 C2 当前阶段投影的数据，不重新验证投影视图，也不创建第二套历史时钟。C1 仍负责首次介绍、主动完成、存储和重播。A/B 专属实现与史料不在本目录修改。

默认入口沿用原首页「开启征程 → 立即进入」。没有正式历史数据时仍可观察现代山河，但不会显示候选事件、渡口或示意行军线。山河取景是现代技术窗口，不改变 C2 专题／阶段。当前发布事件和真实历史路线仍为 0。

| 模块                     | 职责                                                           |
| ------------------------ | -------------------------------------------------------------- |
| `ExhibitionPanorama.tsx` | 原展馆内的视角、现代取景、图层、已发布事件题字、主动阅读及书签 |
| `map-renderer.ts`        | 真 WebGL、视线避障、镜头／标志投影、按阶段路线与态势区域、清理 |
| `modern-landscape.ts`    | 全景与八区域 LOD、共享岸坡／水面、现代水系、光雾与地域缓存     |
| `map-objects.ts`         | 从 C2 已发布投影视图取得当前阶段可绘路线                       |
| `map-regions.ts`         | 当代地理取景窗口与名称；没有历史日期／部队／事件坐标           |
| `data/`、`assets/`       | 离线现代高程、水系、OFL 字体、CC0 通用岩石与追溯文件           |

`src/app/panorama/` 保留隔离候选 UI、四渡非地理工程板和开发兼容出口。正式构建继续拒绝它及测试／fixtures；正式 App 只从本目录导入允许的现代地图内核，不整包携带开发原型。

历史事件坐标未知时不绘点；确认地点模式不连线；示意路线只按来源顶点画虚线；阶段切换只替换 C2 当前资料，不推算中间位置、行军速度或部队人数。河宽、深浅、地势与镜头是艺术显示，不能用于历史或地理量测。

地图首帧真实渲染成功才反馈宏观场景 ready，与沉浸体验 ready 分离。着色器错误、上下文丢失、加载超时走原有错误／重试路径；退出释放控件、RAF、几何、材质、纹理与环境资源。后台隐藏原生专项仍未验收。

首页与地图的光色、材质和空态衔接见[展馆视觉修正记录](../../../docs/design/panorama-exhibition-refinement.md)。

连续总图的默认瑞金取景、同画布区域／内层定位与 A 八区公共模块接入见[新版集成记录](../../../docs/architecture/continuous-panorama-a-integration.md)。旧[瑞金展台记录](../../../docs/design/ruijin-entry-relief.md)仅保留被用户否决的独立切块审计，不再代表当前效果。

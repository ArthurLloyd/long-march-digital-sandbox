# C：正式展馆的现代全景地图

`ExhibitionPanorama` 接受既有 `LongMarchSceneV2Props`；它消费 App 已验证、已发布且按 C2 当前阶段投影的数据，不重新验证投影视图，也不创建第二套历史时钟。C1 仍负责首次介绍、主动完成、存储和重播。A/B 专属实现与史料不在本目录修改。

默认入口沿用原首页「开启征程 → 立即进入」。没有正式历史数据时仍可观察现代山河，但不会显示候选事件、渡口或示意行军线。山河取景是现代技术窗口，不改变 C2 专题／阶段。当前发布事件和真实历史路线仍为 0。

| 模块                                           | 职责                                                           |
| ---------------------------------------------- | -------------------------------------------------------------- |
| `ExhibitionPanorama.tsx`                       | 原展馆内的视角、现代取景、图层、已发布事件题字、主动阅读及书签 |
| `map-renderer.ts`                              | 真 WebGL、视线避障、镜头／标志投影、按阶段路线与态势区域、清理 |
| `modern-landscape.ts`                          | 全景与八区域 LOD、共享岸坡／水面、现代水系、光雾与地域缓存     |
| `terrain-tile.ts`、`terrain-lod.ts`            | 全域／区域／局部最多三层显示网格、接边、滞回和300ms近景细化    |
| `terrain-navigation.ts`、`terrain-requests.ts` | 真实地表双击聚焦、统一相机安全约束、末次请求和有限缓存         |
| `map-objects.ts`                               | 从 C2 已发布投影视图取得当前阶段可绘路线                       |
| `map-regions.ts`                               | 当代地理取景窗口与名称；没有历史日期／部队／事件坐标           |
| `data/`、`assets/`                             | 离线现代高程、水系、OFL 字体、CC0 通用岩石与追溯文件           |

`src/app/panorama/` 保留隔离候选 UI、四渡非地理工程板和开发兼容出口。正式构建继续拒绝它及测试／fixtures；正式 App 只从本目录导入允许的现代地图内核，不整包携带开发原型。

历史事件坐标未知时不绘点；确认地点模式不连线；示意路线只按来源顶点画虚线；阶段切换只替换 C2 当前资料，不推算中间位置、行军速度或部队人数。河宽、深浅、地势与镜头是艺术显示，不能用于历史或地理量测。

地图首帧真实渲染成功才反馈宏观场景 ready，与沉浸体验 ready 分离。着色器错误、上下文丢失、加载超时走原有错误／重试路径；退出释放控件、RAF、几何、材质、纹理与环境资源。后台隐藏原生专项仍未验收。

桌面滚轮以鼠标下真实命中的山坡／河面为锚点缩放；同时平移相机和观察中心，保持该点的屏幕位置，地表碰撞保护优先。空白不降级为屏幕中心缩放。双击可把观察中心移到命中位置，再用滚轮、加减按钮或键盘继续靠近。界面控件和拖动不触发地表聚焦，用户输入可中断镜头飞行；Home 或“全景”返回。共享 `heightAt` 采样当前实际三角面（包括细节接边、显示夸张与河床），`waterHeightAt` 单独返回河面高度／null。后续悬浮标志可使用 `heightAt(x,z)+偏移`；本轮未新增部队箭头或行军逻辑。

右侧默认只显示“地图工具”收纳入口。展开后在同一个非模态侧栏中操作视角、山河取景、地势／图层、当前阶段态势与区域艺术／正文入口。侧栏按桌面高度限制自身高度、内部滚动；Esc 或“收起”关闭并返回入口焦点，不卸载地图。左侧保留题字与史实资料。渲染器异常时 App 仍提供原部队态势说明和文字资料路径。

普通缩放也会按目标位置载入已有区域DEM；专题外使用原全域DEM的局部显示重采样与材质，不产生新真实高程。仅保留三项字段缓存、一个区域层和一个近景层，异步旧结果、返回全景和退出均使请求失效。可选 `?terrainMetrics=1` 只在现有 Canvas 输出只读实测属性，记录真实相机、RAF帧间隔与渲染资源，不修改镜头或历史状态。验收范围和精度限制见[本轮记录](../../../docs/architecture/phase-terrain-02-report.md)。

首页与地图的光色、材质和空态衔接见[展馆视觉修正记录](../../../docs/design/panorama-exhibition-refinement.md)。

连续总图的默认瑞金取景、同画布区域／内层定位与 A 八区公共模块接入见[新版集成记录](../../../docs/architecture/continuous-panorama-a-integration.md)。旧[瑞金展台记录](../../../docs/design/ruijin-entry-relief.md)仅保留被用户否决的独立切块审计，不再代表当前效果。

## C-EVENT-MAP-01 附加展陈位置

正常展馆由 App 额外提供完整 EventMapModel，和原 C2 阶段 dataset 分离；strict 输入继续只使用原审核坐标。EventMapLayer 复用 setMarkers 的 DOM 投影、heightAt 和同一 Canvas，远景聚合、近景展开、屏幕标签避让与按压期间的指针捕获均不改变经纬度。setEventAreas 仅绘制闭合区域参考；focusGeo 可带展陈 bounds，并保留原单点调用方式。

“事件地图”目录、地点预览与既有正文共享事件ID；阅读暂停原C2时钟、保存书签，关闭恢复选择，不自动完成C1或播放艺术视频。失效数据清空附加标记/引用，不以失败回退重开旧事件。见[事件位置说明](../history/event-map/README.md)和[本轮验收报告](../../../docs/architecture/phase-event-map-01-report.md)。

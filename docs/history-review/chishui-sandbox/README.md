# 四渡赤水 · 战役沙盘

本次将四渡赤水区域入口接为原创程序三维战役复盘。采用项目现有泸定桥的深色青绿、金色线框、分卷标题和观景控件语言；全部新叙事与新绘制均为四渡赤水，没有挪用泸定桥的桥体、战斗脚本或视频。

## 观看与操作

从正常展馆进入赤水区域的沉浸探索，将直接打开“**四渡赤水 · 战役沙盘**”。默认暂停，点击播放开始约 88 秒的四幕演示。四次渡河支持直接选幕；选幕和拖动进度暂停回放，以便观察。0.5/1/1.5/2 倍速、上一幕、下一幕、从头回看、跟随讲解、俯瞰全局与自由环顾可用。镜头按钮用于恢复导览；拖动仅转为自由镜头，不改变历史顺序。切到后台会暂停，回到页面后主动继续。

右上角可看史料与表现说明。语音按钮使用设备支持的中文语音；无法提供中文语音时以文字为准，不下载第三方音频。小屏仍保留播放、阶段、镜头与正文。三维能力不足时自动显示可操作的平面示意。

“河谷漫游”保留原赤水区域空间；该空间工具栏中的旗帜按钮可回到战役沙盘。返回总地图仍走原回调，其他七个区域不变。不写 C1 完成证据，不自动标记学习完成。

## 画面边界

- 原创浮雕地形、河道、地名摆放和行动线均为局部艺术示意，不是实测地图或历史路线复原。没有经纬度输入，没有写入任何历史路线或坐标。
- 红色表示主力行动方向，蓝色为追堵压力意象。小人物、旗帜、闪光不代表具体人数、伤亡、装备、炮火或精确驻地。
- 分幕按一渡 1 月 29 日、二渡 2 月 18—21 日、三渡 3 月 16—17 日、四渡 3 月 21—22 日组织；叙述保留四渡以后继续南下的过程。
- 内容是新的程序艺术再现，没有真人历史对白、没有生成真实人物肖像、没有使用参考作者的代码或视频素材。
- 抖音参考链接未能访问，不能声称逐镜复刻。实现只采用用户确认的“沙盘复盘、依次渡河、追堵态势、讲解镜头、可控回放”结构和本项目已有风格。

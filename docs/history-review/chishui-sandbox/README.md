# 四渡赤水第二版：双方面势与因果讲解

本版继续基于队友的行进集成快照 8fb55a843e0d78def6feb56e4f403f48d94c2117，以及上一版四渡赤水沙盘交付。针对正常展馆总地图，不再只修改独立近景沙盘。

## 三处实际改动

1. **地点标签区分事件与关联渡口。** 土城显示“一渡赤水 · 土城”，猿猴场显示“猿猴场渡河（同属一渡）”。二渡、四渡也分别标出太平渡和二郎滩。保留全部地点记录、坐标、出处和点击正文，不删除合法的关联地点来掩盖重名。
2. **蓝色追堵线。** 增加 10 条有来源的战略方向或防堵范围记录，总数从 27 条增至 37 条，其中蓝方 11 条。覆盖土城前后的迂回堵截、川军北面进逼扎西、滇军南面进逼扎西、二渡后的川军东追、黔军北援与吴奇伟部增援、三渡前桐梓向遵义的压迫、四渡前的河西追击与叙永古蔺防堵。蓝线使用固定像素宽度叠加在地形上，避免普通一像素线被山体吞没；背景方向线与已演示部分分开。防堵范围不作部队行进；仅为调动情报的原范子英旅记录不自动演成已完成调动。
3. **场景里直接讲原因、行动和意义。** 正常地图新增可收起的战况面板，随同一行军时钟切换讲解。六个相关章节、18 段讲解涵盖战役开端、一渡、扎西会议、二渡及遵义战役、三渡和四渡；每段均有敌情、应对、意义和史料入口。五个相关正文扩展同步补充。近景沙盘也使用同一套因果内容，并增加实在的蓝色追堵线，不再只有蓝色箭头装饰。

## 节奏与控制

四渡赤水相关章节延长展示时间，以容纳阅读；仍然只是展陈时间，不代表历史时长。原“一渡播放约1%即触发到达停靠”的设置不再中断战况讲解：这些章节使用可选 pauseAtArrival=false。用户可以主动暂停、拖动、点选“敌情/应对/转机”步骤和“阅读本幕史事”。其他章节保持原停靠行为；没有新增第二个宏观时钟，没有写学习完成证据。

精确点选 28% 和 60% 时使用极小数值容差，避免浮点舍入把“转机”误留在上一段。该容差只用于界面分段，不改变历史日期或地理位置。

- 原 `src/data/verified/dataset.json` 保持逐字节不变；既有审核与 release 状态未改写。
- 新内容在原展馆补充层登记，新增史料仍为 draft/unpublished，没有冒充人工签名。
- 高县、毕节为新登记的现代同名地区定位参考，P625 度分秒取自 Wikidata Q693612/Q486319，并记录日期和 CC0。它们只支撑方向锚点，不是1935年城界或部队驻地。
- 指向扎西的蓝线用地区锚点示意，不把史料中的大湾子强行落到扎西镇中心。叙永—古蔺范围线不声称沿线存在连续实测封锁阵地。

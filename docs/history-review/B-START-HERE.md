# 现在直接打开实际展馆

本轮为2026-11-02完整接入版。请先读[B-INSTALL.md](B-INSTALL.md)：它包含完整源码运行、把增量补丁应用到原仓库、测试、提交和创建PR的全部步骤。

正常运行 npm.cmd run dev 后打开终端给出的首页地址即可；不需要另开review页面。

“开启征程 → 立即进入 → 历史专题 → 阅读某个专题”。同一面板可以查看完整正文、关联人物和地点，或开始图文互动。人物面板中可查看照片/艺术形象与出处。泸定桥、遵义会议、雪山可打开既有区域场景演绎，再返回资料。

开发运行与构建预览均包含已准备的全部内容。本轮355项测试通过，详细检查及实际浏览器限制见[接入记录](exhibition-integration-report.md)。

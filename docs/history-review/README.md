# 人工复核记录（B 维护，团队复核）

此目录只包含真实人工复核及工作单，不预填任何审核通过结果。

新建工作单时复制下列结构到独立 Markdown 文件，保持未审核状态：

```markdown
# 复核工作单

- 涉及事件／路线／来源 ID：
- PR 链接：
- 状态：待人工复核
- 核对内容：日期、地点、人物、部队、顺序、结果、引用上下文
- 路线几何证据、原始坐标系与精度：
- 来源文件与页码／章节：
- 权利、素材与公开地图展示核查：
- 争议与证据局限：
- 复核人员一：待真实人员填写；明确决定、时间、证据范围、本人 PR 评论链接
- 复核人员二：待另一位真实人员填写；明确决定、时间、证据范围、本人 PR 评论链接
- 发布决定及执行人员：待填写
- 后续修订／撤回记录：
```

人员 ID 用各自稳定 GitHub 登录名，两位必须不同。AI 不得把模板填成 approved，也不得代替人员写评论。同意记录由人员本人留下，C 逐项核对后合并；数据修改后重新复核，保留旧记录。

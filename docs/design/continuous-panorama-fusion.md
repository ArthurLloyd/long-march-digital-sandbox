## A 原版艺术空间的接入

“走进艺术场景”通过公共懒加载出口打开 A 的 `RegionalObservation`。人物、房舍、桥谷、雪山／草地意象、开场影片、三项观察、思考反馈、回到初景及区域切换沿用 A 原实现。打开时暂停总地图绘制；退出释放区域空间并恢复同阶段书签，阶段已变化时拒绝恢复旧阶段书签。

采用 A 提交 `0a17abdb7ce760826730b6d08580ecafc292bdde` 的实现，16 个核心源码／测试文件保持 Git blob 一致，见[一致性清单](../architecture/evidence/continuous-a-integration/source-blobs.json)。必要适配限于公共出口与共享地理类型边界；没有把两个完整地图渲染器叠在一起。生产艺术资源只允许[明确清单](../../scripts/a-art-assets.json)中的 22 个文件，每项固定路径及 SHA-256，不放开整个素材目录。

局部艺术空间使用自身艺术坐标，不拼接成真实 DEM，不向 C2 回传虚构位置、兵力或行军路线。影片秒数只表示片段播放，观察与思考不写 C1 完成记录，不推进第二套宏观历史时钟。

## 发布与验收边界

正式历史事件与真实历史路线仍为 **0**，正式数据、人工审核字段及双人复核门槛不变。地势增强、水面宽深、色层及全图外缘厚底属于艺术显示，不用于历史或地理量测；厚侧壁不代表真实地下地层。

A 空间及影片保留艺术／AI 标识。匿名人物数量、服装、摆放、桥板和建筑不构成历史实测或史料发布；AI 远景不是历史照片，球面背面无缝性尚未验收。艺术观察不改变真实历史过程及结果。

本地组合测试为 **45 个文件、340 项通过**，保留 C0/C1/C2 与 A 原测试，覆盖同画布定位、区域／内层镜头、地表及水槽接线、背景绘制暂停／恢复和跨阶段书签拒绝。主任务已记录实际预览操作；最终 head、CI、PR、合并 SHA 及 main 复验由 PR 台账维护，本文不预填后续结论。

未开展 C3-C、手机端精修或应用封装。原生后台隐藏专项保持未验收，背景画布在艺术空间打开时暂停不等同于该专项通过。持续 GPU 性能、全设备、影片逐音试听及完整无障碍认证不在本轮结论内。

根设计规范仍保留旧阶段说明及通用字号，未覆盖本轮连续地形和局部两字字库。本页记录实际差异，不顺带重建根规范或 sidecar。

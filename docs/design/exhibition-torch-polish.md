## 同一地图中的程序三维火炬

火炬是 C 在现有 Three.js 场景内创建的原创展陈雕塑，包括铜制火盆、木柄、缠带、多层火焰和局部暖光；不是历史器物复原、部队数量或史料。入场时放大，一般视角中缩小，大小随镜头距离限制在有限范围内；与地图共用地表高程和渲染生命周期。

位置来源严格分开：

- 没有当前历史阶段且处于瑞金取景时，使用既有现代区域中心显示启程意象；它不是经核验的历史部队位置。
- 当前阶段恰有一个合法、已发布的红军点态势时，火炬采用该点。多支部队仍由各自标注的态势图层表达，不计算中心点。
- 位置未知、越界、隐藏、撤回或无法唯一确定时隐藏火炬。不补造坐标、路线或阶段间移动轨迹，不进行位置插值。

减少动态模式停止火炬悬浮、火焰摇动与光强摆动，并关闭本轮控件及手记的 CSS 动画和过渡；位置及操作仍可使用。退出时释放新增几何、材质和灯光，重复清理保持安全。

## 八区共用手记外观

C 只在 `museum-art-space` 限定容器内覆盖 A 的手记／观察／思考面板样式：以墨蓝底、金线内框、暖金标题和朱红操作衔接展馆；正文与思考区形成清晰分栏，选中观察项和作答反馈使用独立底色。面板限制高度并可滚动，避免遮住全部场景；短屏减小内边距，窄屏样式改为单列。

A 的 16 个核心源码／测试文件保持原 Git blob，不改场景、影片、三项观察、问答逻辑、艺术完成边界或资源释放。原一致性依据见[源码清单](../architecture/evidence/continuous-a-integration/source-blobs.json)。艺术观察仍不写 C1 正式历史体验完成记录，也不推进第二套历史时钟。

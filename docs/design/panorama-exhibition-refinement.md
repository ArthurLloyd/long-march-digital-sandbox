# 全景地图与展馆首页的视觉衔接

记录日期：2026-11-02。用户指出已接入原探索页面的地图仍显普通，与首页的山河展陈缺少整体感。本轮针对这一视觉问题修正材质、光雾、水面、空态及控件，没有重新建设首页或改动地图数据、几何和历史流程。

实现分支为 `codex/panorama-exhibition-art-direction`，基于 main `6444d1c56f7caf160a5eb5be042500af58745514`。本报告记录实现与合并前验收；最终 PR、准确 head／合并 SHA、CI 和 main 复验由对应 PR 描述维护。既有生产接线见[全景集成报告](../architecture/panorama-framework-report.md)，该阶段记录保留原样。

## 视觉依据与保留范围

方向取自未改变的首页山河背景：墨蓝与炭色山影、银灰雾层、山脊和地平线的克制暖晨光，配暖纸文字、金线和朱红动作。地图延续这种冷暖与明暗关系，同时保留现代高程的相对格局；不把首页艺术画面投射为真实地形，也不更换整套视觉世界。首页画面制作与证据边界仍见[原素材记录](hero-art-provenance.md)。

`PRODUCT.md`、`DESIGN.md`、`.impeccable/design.json` 和首页素材保持不变。修正仅在 C 所有的现代场景与探索覆盖层中实施；相机模型、地形／水体几何、原始高程与中心线、C1 生命周期、C2 阶段、公共契约和发布规则不变。没有新增栅格素材、字体或其他授权依赖，现有来源和许可清单继续适用。

## 五项修正与复查结论

独立评审先对照首页／背景与七张原地图截图，指出以下五项具体差异；随后对本轮六张当前截图重新复查。

| 问题                                            | 实际修正                                                                                                                                                      | 当前结论                                                                 |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 1. 地形材质与光照偏日间橄榄绿、米色，与首页脱节 | 统一 `EXHIBITION_LIGHT`，降低直接贴图色相对地形的支配，以墨影、蓝灰岩面、低饱和山色建立体积，再让暖晨光有选择地落在明部。二次修正补回暖光比例，避免整体过冷。 | **Resolved**，最终同一评审认可本轮限定修正。                             |
| 2. 大气层次偏绿灰、地图像矩形板                 | 地形与水体共享高度／距离相关的谷地空气透视；外围在输出阶段向同一天空颜色过渡，避免深色矩形边框。暖雾与冷影共同分层，不靠整屏染色。                            | **Resolved**，二次暖光／大气修正后的当前截图已复查。                     |
| 3. 水面像青色线带，后续版本又过暗               | 调整为有深浅、细微波纹与银金反射的水面；显式绑定共享 PMREM 环境，使水体独立反射强度生效，避免沿用较低的地形环境强度。材质不拥有环境贴图的释放权。             | **Resolved**，最终复查确认暗河问题已修正；不构成水文流向或实测水深验证。 |
| 4. 历史空态重复、底栏占据地图                   | 无可发布阶段时，合并为一个明确核验说明，收起重复专题／态势覆盖层；该空态底栏从 210px 收紧至 144px，移除端点卷轴，保留原历史控件的禁用语义。                   | **Resolved**，二次光照修正未重开此项。                                   |
| 5. 控制面板与来源文字仍像另一套界面             | 面板、标记与交互反馈复用既有墨蓝表面、金线、正文／次文 token；来源改为可展开的紧凑说明，OSM 归属保持可见。                                                    | **Resolved**，二次光照修正未重开此项。                                   |

最终同一评审重新打开六张当前截图，给出 `ship`：五项原始问题及后续过冷、暗河两项修正均在本次范围内关闭。结论仅覆盖提供的桌面静态展陈状态，不是整个场景、照片级真实感、所有机位、移动端或持续性能认证；最终审美判断仍以用户反馈为准。

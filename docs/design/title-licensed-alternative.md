# 手迹图版未获明确使用条件时的替代准备

当前首页按用户确认继续使用手迹取字。本轮没有取得扫描图版的改编、再分发或公开展示授权，不将“网站可访问”写成授权。来源与权利记录继续保留，不删去署名。

已准备独立的备用标题图 `fallbacks/title-ofl.svg`：使用现有依赖 `@fontsource/noto-serif-sc@5.3.1` 的600字重排“长征”，暖纸色、疏朗横排，保留现有副标题和页面构图。图中嵌入所需的原始WOFF2分段，不依赖第三方图片服务或用户系统字体。它是普通授权字体排版，不能称作毛泽东本人手迹。

字体包许可为SIL OFL-1.1，原许可、版权信息见 `public/licenses/OFL-1.1.txt`。完整字体数据没有重绘、改名修改或伪装为手书。此项只确认现有字体包的许可记录，不代表对其他素材或整个展馆作法律认证。

生成命令（已安装npm依赖后、本地执行，无网络请求）：

```powershell
node docs/design/fallbacks/prepare-title.mjs
```

该SVG为备用方案，尚未切入当前首页，未完成浏览器渲染验收。公开交付前，如果仍不能明确手迹扫描图版的使用条件，可将它复制到正式素材目录，并把h1中两张手迹图片换为这一张图，保留h1可访问名称，统一检查比例、缩放和页面构图。届时在交付包中排除手迹PNG，并同步更新关于展馆、来源记录和截图。

不能仅通过隐藏手迹图片来宣称交付包已排除它：切换后还需检查生产构建文件、源文件交付范围及缓存。准备替代方案不等于已获得手迹授权，也不等于已完成公开交付。

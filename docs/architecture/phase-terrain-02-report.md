# C-TERRAIN-02 连续地形与近景观察验收

记录日期：2026-11-03。分支 `feat/terrain-closeup-refinement`，基线 `10e9ce7240816f51840902e4cba4936666d02a81`（含 PR #22 的完整正文与互动展出）。工程实现冻结提交 `dfedab2e7f5975d4550e24ce32df9129356ccb41`；报告与证据为随后独立文档提交，最终 PR head 以 PR 台账为准。本轮不合并 main、不部署、不合并 #12/#15/#17，不改变 A/B 源文件、历史坐标、路线与审核字段。

## 已确认的原因与修正

原相机最小距离为 0.18，近裁剪面 0.02，宏观取景目标还额外高于地表 0.09。以每世界单位十万米的投影尺度看，这些值不能作为近景安全余量直接沿用。缩放始终围绕旧区域目标，且区域 DEM 只由专题取景按钮加载；全域细起伏被压低，区域切换会替换整组河流。原区域显示网格为 769×641，增加全图密度并非合适的解决方向。

保持原 Three.js、Web Mercator、同一 Canvas。最小距离改为 0.004；near 按距离限制于 0.00005–0.02，far 为 12–160。相机与近裁剪面九个采样位置都使用当前地表／水面安全约束，旧区域书签的过大空中目标高度随接近逐渐消除。只保护相机近体积，允许自然山体遮挡，不把近景持续抬回全景。

双击真实地表／河面进行射线拾取；无效、空白、UI 和拖动不触发聚焦。用户输入取消旧飞行，后续有效聚焦覆盖之前目标。按钮、键盘、滚轮、自动飞行和书签恢复共用相机安全约束。

用户追加的滚轮需求采用真实命中点为缩放锚：相机及观察中心同时围绕命中点缩放，保留该点屏幕位置；碰撞安全优先。不是仅围绕旧中心的平面投影，也不是缩小 FOV 或放大 Canvas。空白不回退到屏幕中心缩放，UI 滚动不穿透地形。

## 连续地表与高度接口

全域保留原网格；区域窗口对齐父网格单元，局部观察层同样对齐父层并接合边缘。最多三个地表网格，没有重复叠放同一表面、独立瑞金切块或额外地图。近景细化在 300ms 内分六步过渡，边界对应父网格实际高度；细化、换档均重新计算法线和包围体。

根据相机目标与距离选择已有区域 DEM，普通滚轮／平移也可加载；专题外使用原全域 DEM 的显示重采样。观察位置稳定 220ms 后才安排细化，并有窗口及比例滞回，避免逐滚轮重建。字段请求缓存最多三项，活动区域与近景各一个；ES 模块最多包含八个既有区域数据，并非无限缓存。最后请求、全景取消和卸载均使旧结果失效，加载失败保留现有底图。

`heightAt(x,z)` 直接匹配当前显示网格的三角面，包括夸张、接边和河床，不保留过期高度缓存。`waterHeightAt` 独立返回水面／null，导航使用二者较高值。后续悬浮箭头可取 `heightAt + 悬浮偏移`；本轮未增加部队箭头、行军播放器、路线动画或历史插值。

## 数据、地貌和河流

原始高程与中心线字节未改。全域为 Mapzen/Tilezen Terrain Tiles z6，采样 385×321，实际为数公里级概化；八区来自 z9、385×321 的数百米级参考。网格细分、双三次采样不构成新增真实高程精度。来源、哈希与许可仍见 `src/app/landscape/data/README.md`、`details/README.md` 及 provenance 文件。

全域细起伏与区域小起伏加强，同时限制局部宽频夸张，保留平原／草地的缓坡。显示档位 1/6/12/24 保留；1× 原始采样不加艺术高度，其他档位不将每个局部尖峰直接乘以同一全局增益。

现有三平面 CC0 岩石纹理与程序微表面继续使用，不增加几何随机位移。川西高山按区域、高程、坡度和斑驳过渡形成白色顶部，陡坡露岩；高原草地以自然深浅绿色为主。裸土／河岸用赭黄褐色，陡坡用灰褐岩色。颜色是地域地貌艺术表现，不是土地覆盖调查，也不复原 1935 年的积雪、植被和天气。

保留 Natural Earth 和原 OSM 水系，OSM 大渡河只在已取得范围内替代概化参考，范围外仍保留原参考段。不同河系采用有限的艺术宽度；河床、岸坡与水面共用同一开槽模型。相连 way 端点使用一致的源采样水位；水面采用不透明深度写入，避免透明叠加发黑。流纹、反射和浅岸颜色使用原渲染循环，没有额外 RAF 或流体模拟。全部宽深与水位处理属于现代参考的艺术显示，不作为历史渡口或水文证据。

### 可重复尺度对比

赤水同一现代水平锚点，前后 x/z 分别为 `-0.8105670835976861, 4.202044059321913`；FOV同为43°、地图视口1920×870。通过正常键盘加号缩放34次取得后图，没有修改localStorage、相机内部状态或Canvas的CSS比例。

| 项目                 | 原版最近视角 | 本轮同锚点近景 |
| -------------------- | -----------: | -------------: |
| 相机到观察中心距离   |     0.180000 |       0.023882 |
| near                 |         0.02 |     0.00028658 |
| 视点垂直平面覆盖宽度 |     0.312955 |       0.041522 |

宽度计算为 `2 × distance × tan(FOV/2) × aspect`；缩小为原来的 **13.3%**（约 **7.54 倍**靠近），优于四分之一的参考目标。这是可重复的投影尺度指标，**不是实测地面宽度**：山坡非平面且做了高度夸张，相机安全保护使俯角有所变化。原 `.09` 空中目标偏移已消除；后图实际相机高度高于当前地表和水面。河段近景另有以水面为主、两岸可见的操作截图，近景纹理不代表新增测绘精度。

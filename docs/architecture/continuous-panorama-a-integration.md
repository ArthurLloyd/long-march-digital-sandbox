## 实际接入 A 的内容

主地图直接调用 A 的 `createEnvironmentDetails`，将 C 的同一地表高程和水槽避让函数注入 A 的实例布置；区域配色使用 A 的 `REGION_MOOD`，在当前区域边缘渐变。没有并排叠放两个地形网格，也没有引入第二套经纬度投影。

从区域的“走进艺术场景”按钮懒加载 A 的 `RegionalObservation`。八区人物、房舍、桥谷、雪山／草地意象、影片、观察点、思考反馈、回到初景及区域切换使用 A 原实现。打开时暂停背景绘制，退出后释放局部空间并恢复同阶段书签；若历史阶段已改变，不恢复旧阶段书签。

这些局部空间是艺术坐标，不拼接成真实 DEM，也不向 C2 回传虚构兵力、位置或路线。影片秒数只表示片段播放，不构成宏观历史时钟。观察进度与思考不调用 C1 完成、事件选择或存储接口。

A 的 16 个核心源码／测试文件与原提交的 Git blob 一致，记录见[来源一致性清单](evidence/continuous-a-integration/source-blobs.json)。必要边界调整仅为公共懒加载出口、环境出口，以及 `regions.ts` 的纯类型引用改为共享 `ModernGeoBounds`；A 的地形、人物、影片控制与 Three.js 核心未被改写。原测试原样保留。

## 生产资源隔离

生产继续关闭整个 `public` 自动复制。`scripts/a-art-assets.json` 只允许 A 原交付的 **22 个精确艺术文件**：八段已选影片及封面、三个背景和三个回退封面。每项固定路径与 SHA-256；修改字节必须更新明确清单并重新审查。不是放开 textures 目录或所有 A 资源。

构建／预览使用同一白名单；不在清单的资源仍被拒绝。原未发布素材字节拦截、改名图片检测、候选文本检测和工作台隔离保留；未发布历史素材不能借艺术清单进入生产。新增测试验证固定艺术字节可输出、字节被改拒绝、未知路径拒绝及未发布字节黑名单仍优先。

正式历史数据、审核字段和双人复核规则不变：正式事件与真实历史路线仍为 **0**。艺术空间及影片常驻艺术／AI 标识，不表示这些内容已作为历史资料发布，也不构成服装、桥板状态或地下地层的真实性认证。

# 主页面方向与验收范围

用户已在任务书指定：历史史诗感 + 现代数字沙盘 + 高端科技展馆；深色、暗红、少量金色；顶部导航、左右面板、中央场景、底部时间轴。本次按该明确方向直接实现，不重新开启视觉方案选择。

首页是历史探索体验的开发预览。当前唯一可验证的产品内容是模块入口、核验说明与空态；不编造历史事件来填充画面，不使用 AI 地形、照片或伪造路线。抽象底座与网格属于场景占位几何，必须持续说明其无历史地理含义。

视觉验收：桌面 1440×900、手机 390×844（完整页面截图）；确认无横向溢出、正文清晰、导航可操作、空数据回放禁用、核验提示可见、无虚构路线、无浏览器错误。主体读序为专题→场景→资料→回放。窄屏转为纵向流。

本次使用代码构建；不生成视觉效果图或引入额外外部图片。字体采用设备已有字体；中文宋体承载历史标题，黑体承载操作与资料。4px 控件圆角，圆形播放按钮只用于媒体控制；面板以细分隔线区分，不做重复营销卡片。

机械检测唯一 advisory：场景占位底座有网格。该网格确实位于沙盘容器上，符合用户允许的背景网格与抽象几何示意，不是页面装饰背景，保留并标注。

当前明确限制：场景只是 DOM/CSS 占位，未验证 WebGL；无正式史实、地图与授权审核结果；无正式历史章节可供回放。后续真实内容由 A/B 的模块 PR 接入。

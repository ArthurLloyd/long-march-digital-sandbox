## 当前渲染边界

`ExhibitionPanorama` 接受既有 `LongMarchSceneV2Props`，输入来自 App 的已发布 C2 阶段投影。它不创建正式历史时钟，不从空数据补造坐标，也不重新将投影视图作为完整候选集校验。当前 C 内部 `src/app/landscape/map-renderer.ts` 的 `PanoramaMapAdapter` 已具备：

| 方法／输入                                          | 语义                                                                                     |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `focus(bounds)`                                     | 技术区域平滑取景，不表示行军路线。                                                       |
| `focusGeo(point)`                                   | 对已有合法坐标取景，不向 B 的 null 字段写值。                                            |
| `setMarkers(markers)`                               | 输入 ID 与 `[longitude, latitude]`，回报屏幕投影；现代区域标志与历史点使用不同语义。     |
| `setRoutes(routes, camps)`                          | 仅绘当前阶段可显示的发布路线，保留 `unitId`、阵营、精度与模式；空输入保持空。            |
| `setForceRegions(state, camps)`                     | 接收 `ForcePhaseState` 的有据阶段区域；无插值、速度、兵力或中间位置推算。                |
| `overview(top?)`、`zoom(direction)`                 | 全景、俯瞰、缩放，用户拖动可中断推进。                                                   |
| `bookmark()`／`restore(bookmark)`                   | `sceneId='long-march-modern-panorama'` 的 scene-local position／target；不是历史经纬度。 |
| `setVerticalExaggeration(gain)`                     | gain 为 1/6/12/24 的显示强度，近景自适配；不是全区域统一量测比例。                       |
| `setRivers(visible)`、`suspend(value)`、`dispose()` | 现代水系显隐、暂停与完整资源清理。                                                       |

首帧真实渲染后才回报宏观 ready；不能将它当沉浸 ready。错误、上下文丢失和超时走原有错误／重试容器。地图主动“阅读事件”前即时捕获书签；返回时校验 sceneId 和 phaseId，恢复上下文并保持暂停。

上表是 C 内部替换参考，不要求 A 导入 app 内部代码。A 应从 `src/features/scene/index.ts` 提供正式 `LongMarchSceneV2` 和 `ImmersiveExperienceRenderer`，C 再经公共契约接线；scene 不反向依赖 app 或 history。现有模块加载器提供发现／注入边界，默认宏观场景仍明确使用 C 现代全景，不能假定新 A 出口出现就会自动替换。变更公共字段、书签 sceneId 或视图参数时由 C 先协调接口文档、消费者和测试。

## 四渡赤水与 B 依赖

`sd-phase-1` 至 `sd-phase-4` 对应开发候选 `event-sd-1` 至 `event-sd-4`，不能用专题总述代替各渡卡片。当前四阶段工程板只使用 0..100 非地理坐标；红虚线、蓝点线、箭头、队伍图标和水系轴是机制演示，不是真实战术复原，不进入生产地图，也不能对齐现代赤水河。

B 下一批须提供每渡地点／渡口证据、原始坐标系与精度、红军各部队路线分段、国军有据阶段位置／区域、先后关系、来源及权利条件，并完成两名不同人员独立复核。缺失保持 null/hidden/unpublished，不连接已知地点补线。正式 `scene-phase-view`／`force-state` 仍是当前阶段空间输入。

## 现代素材与视觉要求

- 八区域 z9 DEM 与现代 OSM 赤水河／大渡河参考已置于 `src/app/landscape/data/details/`，高程原始值、原中心线、way ID、下载来源和哈希保留。OSM 为 ODbL 1.0，不能按程序代码许可处理，不能自动成为历史渡口证据。
- 全景 z6 和区域 z9 的显示平滑、垂直表现、河槽、河宽、水深、岸坡、波光、光雾均为艺术处理，不写回原数据。水面、河床与岸坡已有共享网格剖面，继续细化时避免裂缝、岸线锯齿、穿山镜头和黑块回归。
- 通用岩石两张 1K JPEG 为 Poly Haven CC0，不是沿线实地地质证据。志莽行书为 OFL 自托管字体；来源、加工和哈希分别在对应 provenance。新增素材不得绕过生产素材允许清单与发布审核。
- 保留现代地理相对格局，事件／区域推进贴近地势且看清河谷；镜头检查完整视线，不仅抬高端点。电影题字使用共享 `src/components/exhibition/CinematicTitle.tsx` 与 `src/styles/event-cinematic.css`，出现时收起冲突界面，点击或 Escape 恢复原操作与焦点，尊重减少动态偏好。
- 延续原展馆青墨／墨蓝、暖纸、暖金与朱红动作，以及宋体、黑体和行书层级；不另造脱离原展馆的最终页面。`DESIGN.md` 和 sidecar 保持既有规范。

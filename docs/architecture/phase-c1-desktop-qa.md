### 发现的问题及修复

1. 工程地图探针从场景顶端铺开，与导航重叠。实际鼠标点击“工程：打开地图事件”曾触发覆盖其上的首页按钮。新增仅工作台加载的 c1-workbench.css，将探针放到导航和选择行下方；重新刷新后地图按钮、书签按钮均点击正确。
2. C1 “取消当前选择”原来是探索主区域顶部未定位的按钮，也落在导航区域。现归入当前节点信息行，保留现有色彩/字体，44px 最小高度，真实点击可取消选择。
3. 开始、继续、完成时原按钮卸载，且该状态没有 bodyHeading，焦点会落到 body。ExperienceHost 现在仅在焦点已离开抽屉时回到现有抽屉标题；正常活跃控件不反复抢焦点。完整回归新增开始、继续及完成后的焦点断言；浏览器再完整重跑常规体验确认。

没有变更 C0 schema、A/B 接口、正式史实/审核、依赖或锁文件。布局扫描只有原有体验标题 24px 未列入 DESIGN.md 字号表的 advisory，不属于本次新增样式；未为消除此提示改写既有设计规范。

## 人工桌面步骤

1. 运行 `npm run dev:contracts`，使用终端实际端口打开 `/__dev/contracts?flow=c1`，核对工程模拟标注与独立开发存储键。
2. 分别在三种桌面尺寸检查首页。开启征程后须主动“立即进入”，等待不自动跳转。原山河、手迹和红金控件保留。
3. 在工程地图报告书签，再从地图、历史专题、时间轴打开事件，均先到介绍；完整正文不提前出现。人物和无坐标地点可从目录读。
4. 常规动态模式开始体验，手动报告 ready、当前段落，然后相邻前进。第二段触发 ld-01，未看全/提交前继续禁用；提交工程响应、读解释并确认，再主动继续。
5. 第四段同样触发 ld-02；工程按钮只验证 B 响应协议，真实排序 UI 待 B。最后一段报告到达及终点，仍须主动完成才读正文。
6. 刷新后同体验直达、另一未完成体验仍首次；重播创建新实例，中途退出保留旧记录，首次中途退出不保存。退出后入口焦点、原节点、阶段和已有书签应恢复。
7. 模拟 WebGL 故障不记完成。改用等价图文，逐段阅读、同样两互动/解释、到终点并主动完成。减少动态不自动通关。
8. 窗口失焦/隐藏后暂停，回来主动继续；检查声音/字幕、Tab/Shift+Tab、Enter/Space、Esc、退出确认与焦点。补充资料关闭不突然播放。
9. 关闭正文保留选择，宏观保持暂停；显式取消选择与返回首页独立。没有 A 书签时不要求伪造恢复位置。
10. 在关于作品先取消清除、再明确确认清除；重新访问应走首次门槛。只清开发体验键，不动正式 JSON 和其他数据。
11. 每个尺寸检查抽屉滚动、长文本、按钮换行、禁用原因、焦点可见、背景不可操作和水平溢出，记录真实浏览器版本和截图。

## 追加：用户两套镜头与贴地箭头要求

底部“俯瞰”采用较近的区域尺度，中央半屏为静止区；箭头进入左右／上下外侧四分之一后启动平滑平移，回到中央小范围后停止追赶。跨区叙事仍保留全景→俯视区间→局部到达，避免把所有区间直接套成近地行进。

“随行”采用斜侧后方约41°的近景陪行，水平距离基准由0.65降至0.15（再乘跟随距离设置），缩小箭头；每轨复用98顶点的细分箭头，各顶点采样可见地表／水面，加相同显示间距。箭头随山坡弯曲，俯瞰仍使用较大平直悬浮箭头。镜头检查中间山脊并适度抬高，不通过拉远来避障；这些仅是战略示意的显示效果，不新增历史坐标或真实道路。

实际操作发现overflow:hidden容器可因原生控件聚焦发生内部滚动，造成地图上移和底部空白；现用高优先级overflow:clip封住地图画布，验收时scrollTop为0，画布top为0。部队名称移到箭头旁侧，避免盖住小箭头；较窄桌面仍持续显示示意性质说明。

实测：近景距离约0.133，观察平面宽约0.199；俯瞰稳定距离约0.742。进度7.8→10.2时观察中心x/z保持[9.89591675,6.90679100]；箭头进入外侧区后，到20.6时中心推进到[9.68348636,6.87082364]，且俯瞰选择保持。诊断为短窗口采样，近景仍记录到约258ms以上长帧，不宣称稳定帧率。

## 2026-11-03 修订：赤水对齐、区域取景与自选角度随行

本节为当前交付行为，替代上节的近地贴坡箭头、俯瞰模式和“缩放不切换区域”描述；旧证据保留作迭代记录。

### 原因与修正

- 箭头旧图形以中心放在采样点，尖端会越过地标；现几何尖端为局部原点，尾部向后延伸。经纬方向使用同一Mercator投影计算。按整个细长箭身足迹采样最高可见地面/水面并加0.12显示间距，避免仅保护中心导致尾部穿山。所有模式使用同一种悬浮图形，几何和材质复用。
- 遵义与赤水现代窗口重叠，旧focusGeo按对象顺序查找；现明确传递章节上下文，自动浏览不会在播放中切换目录。没有移动史料坐标、区域地理数据或A模型。
- 旧播放按钮把自由模式改成随行，到达回调还会触发近景；现播放不改模式，沿箭头实际位移同时平移相机和观察中心，保留手动调整的角度、距离及相对构图。只有显式点“随行”才恢复区域中远景。
- 默认跨区镜头为宽幅地表环境，取消全景/区间两次跳变；跨区演示独立加快1.8倍，仍停在最早未阅读事件，3秒后自动开卡机制保留。
- 5.5/7距离滞回控制区域事件展开；滚轮命中地表决定区域，缩小到19以上平滑回完整总图。区域地名随真实尺度出现，不依赖点“全景”。手动浏览不改变演示时间。
- 入口清除遗留的安全区投影视口偏移，保证瑞金地形/火炬在右、题字在左。隐藏展馆里的区域包络与标签引线；取消工具栏和底部俯瞰选项，保留河流、全景和红蓝战略虚线。

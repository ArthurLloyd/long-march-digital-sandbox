## 系统与数据边界

复用原首页、Header、SceneViewport、C连续地形及A公共区域体验；不更换引擎、不复制A的Three.js实现。C2 `usePhaseClock` 的连续扩展与原四秒阶段调度互斥。渲染器和低频React界面读取同一个transport；到达后的三秒只是阅读提示延迟，不推进历史时间。

故事打开、来源跳转和人物关联统一进入中央阅读面。正常展出沿用既有 exhibition 策略；strict消费者继续走原发布门禁。原始 `src/data/verified/dataset.json` SHA256 为 `2c45a680a291f0cee795c4388a448de0bd09dbef655a19748b4d05d40f48eb4b`，本轮保持不变。A/B专属源文件没有修改。

新增C资源保持draft/unpublished、真人审核为空。瑞金机关转移、于都集结、于都河夜渡分别叙述；达维／懋功、永坪、吴起、甘泉、甘孜、会宁、将台堡分别登记。现代定位参照不回填历史坐标。永坪日期差异和甘泉多条现代坐标声明保留在来源与定位记录。

## 验证结果

本地执行 npm ci、lint、typecheck、format:check、test、validate:data、build、git diff --check。57个测试文件、429项测试通过。沙箱首次阻止本机Vite端口连接的EACCES在主机环境重跑通过，未绕过隔离测试。保留原C1/C2和旧展馆兼容覆盖，另测新正常主站、真实B五段互动／解释确认／主动完成／重播、33次章节接线、确定性采样、路线显露与箭头同位、方向、暂停、反向seek、倍速、三秒提示及取消、手动已读不重弹、A范围／进度恢复。

本轮后续追加：于都之后的跨区衔接、全部中央主线区域变化、窄长尖尾箭头，以及 eye/target 同步跟随；区间预览虚线和已行进亮线分别持有几何。跨区阶段持续标注“跨区战略示意 · 非历史道路”。共新增13条现代地名参照与10条历史方向来源，保持C草稿状态。军队名称随具体方向分别显示，会宁与将台堡不冒充同一支部队的连贯移动。

原工程提交 `a8cde810c431b20ca48d0491df15c9d8456eaea1` 的 [CI #41619715506](https://github.com/ArthurLloyd/long-march-digital-sandbox/actions/runs/41619715506) 已通过。后续收尾修复与证据提交的最终head及其最新CI记录在PR描述交付台账；不以先前CI替代最终head检查。

# Phase C1：路由、运行实例与本地记忆设计

日期：2026-11-01。实施基线 C0 `6f384d2`。PR #4 已核对为 open、未合并、CI 通过；C1 在独立 `feat/c1-experience-controller` 开发，先建立指向 feat/app-shell 的 Draft PR，不改 PR #4，也不自动合并。

## 范围与兼容审计

保留 landing → entering → exploring 和主动确认。新历史体验是 exploring 内部的独立 reducer；不改 A/B 实现、正式 JSON、史料或审核。复用 C0 的所有 schema、五类互动和完成纯函数，不增加依赖、不做 C2 播放器。

C0 缺口是发布过滤后撤回 manifest 的关联会消失，若仅把“没有已发布 manifest”当普通事件，就可能绕过首次门槛。C1 首先取得发布视图，所有显示内容与准入均从该视图读取；另外从结构合法的体验关联保留仅用于拒绝的产品门槛索引。该索引不提供标题、正文、素材或开放凭证，只阻止撤回/未发布体验降级成普通阅读。不会按标题或固定体验常量猜事件。缺失引用和非法候选整体关闭访问。公共 schema 与 A/B props 不变，后续可由 B/C 另行协调持久门槛绑定字段。

比较了修改事件 schema、候选内容直接接入、独立限制索引三种方式。选择限制索引，保持 C0 消费者兼容并避免未审核内容参与展示；访问授权始终只认 getPublishedDatasetV2 的结果。主题阅读同样不提供绕过已关联主体验的全文入口。

## 路由与适配器

openHistoricalObject 是地图、章节、时间轴手动点击、人物/地点目录和关联导航的唯一入口。普通已发布对象直接读；重点对象先找已发布体验，再核对有效完成记录。自动播放只变沙盘摘要，不调用此入口。已完成可以重播；撤回无论有没有记录都不可用。

A/B 新导出通过应用层可注入 ExperienceModules 接入，缺失则如实提示。正式入口动态读取实际模块出口，不强行导入不存在的组件。测试/工作台注入工程探针，生产入口不导入 fixtures。

## 状态机与顺序

idle、intro、loading、playing、paused、awaiting_interaction、equivalent_experience、ready_to_complete、reading、error、unavailable、exit_confirm。单一 reducer 保存 run、段落序号、到达状态、互动响应、解释确认和退出恢复；宏观时间与首页 reducer 独立。

每次开始、重播、重试、切换等价流程生成新 runId。回调必须匹配 experienceId/scriptVersion/runId；段落仅可先报告当前段已到，再按相邻顺序报告下一段，不能越过未完成的互动。未 ready、暂停、退出或失效脚本回调不推进。终点须在最后一段实际到达后报告，不能直接完成。

互动 cue 属于当前已到达段落。五类响应严格验证类型、材料/选项、完整排列或一一对应；观察允许增量查看，listed 必须遵循顺序。完整但答错的尝试可读反馈/解释后继续；不完整或越权 ID 不可确认。解释确认后仍需明确继续，重复操作不重复计数。

完成只由主动按钮调用 canCompleteExperience 并验证运行状态，生成 completionRecordSchema 合法记录。没有定时通关、故障通关或自动跳正文。

## 存储与并发

独立 CompletionStore 封装键 long-march.experience-completion.v1。版本化 envelope 内仅保存清除代际及六个产品 ID 的 CompletionRecord；每个 ID 保留最近两个规则版本，总计最多十二条，防止错误版本缓存阻塞重新完成当前规则。每条复用 C0 验证，并按 manifest 的规则版本核对。普通改字不失效。

损坏项丢弃并提示，读写被拒绝时会话内仍可完成。保存前读盘合并；同体验保留较新规则/记录，不把未完成状态写回。storage 事件重新读取当前磁盘，防迟到事件覆盖。显式清除写入新代际，其他标签不能将旧缓存重新合并回来。localStorage 不具强事务，常见并发为尽力合并，不能承诺严格原子一致。

清除入口先明确确认，只删体验完成记录，不动史料或审核；关闭、退出、重播取消不清除旧记录。

## 上下文、等价与媒体

进入先显式 pause 宏观播放，保存 selection/phaseId/已有合法 CameraBookmark 与入口焦点；没有书签不虚构。退出/完成后宏观仍暂停，普通关资料保留选择，显式取消和回首页分别处理。书签按 sceneId、phaseId、scene-local 与有限数值校验。

无 WebGL、故障、减少动态或主动选择时，可重启为已发布等价内容，完整逐段阅读并完成同样两个互动。缺内容/组件时不可假通关。等价终点仍需主动完成，记录 equivalent。

页面隐藏/blur 暂停命令和音频，回来由用户主动继续。退出确认先暂停，取消不突然播放。实例卸载要求 A 清媒体/GPU；C 卸载渲染器、取消超时和监听。

## 界面与验收

复用 ExhibitionDrawer 的焦点、Tab/Esc、遮罩与返回焦点，不叠加全局模态管理。采用已有墨蓝/朱红/暗金、阅读字号与原生 CSS；新增播放、静音、字幕、退出、反馈、缺项与清除确认状态，不改首页图形。不做手机精修。

新增路由、状态机、五类响应、存储故障/多标签、等价流程、上下文/焦点及真实应用集成测试。旧关闭资料测试按明确的新产品要求更新为保留选中，并保留其余旧回归。生产隔离插件保持开启。

桌面 1920×1080、1440×900、1366×768 使用已标注工程样本验功能；工具无法访问时记录错误并交付人工步骤，不把 jsdom 称为视觉验收。最终运行全部质量命令并提交独立 Draft PR，停止在 C1。

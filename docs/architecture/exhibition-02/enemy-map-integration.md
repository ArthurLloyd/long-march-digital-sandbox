# 敌军态势接入主地图

本轮直接扩展 C 的地图行军层，复用红军所在 Canvas、地理投影、地形高度、标签避让和唯一 C2 时钟。原 A 四渡赤水实现保留。

表达分为两类：史料明确地名先后或调动方向的，显示蓝色虚线与移动箭头；只确认守备、堵截或逼近某地区的，显示蓝色单点守备/压力符号，不给它补造一条来路。单点与方向均采用有出处的现代同名地点作为 schematic 锚点，不提升为精确军事位置。

数据保存在 C 自有补充层：新增来源、现代定位参考、方向轨道和单点部署。字段逐项校验章节、时间窗口、出处、定位参考及一一对应关系。新的单点证据类型与移动方向分开；单点采样始终不动，也不生成线。暂停、seek、重播、章节切换及原红蓝图层开关直接作用于同一渲染层。

优先补全赣南封锁、湘江追堵、通道转兵的湘西压力、贵阳/云南调兵、大渡河守备、翻山前芦山宝兴防线、松潘包座增援、腊子口/岷县守备、吴起尾追与会师周边压力。没有可定位依据的敌军动作继续不绘制，不从红军轨迹反推敌军位置。会师不是交战，不强制在每一个会师点放置敌军。

实现不改 B verified JSON、不生成真人复核，不改 A 的局部三维场景、不创建第二个时钟、不合并 main。工程验证覆盖真实 Three.js 对象、图层开关、暂停/拖动一致性、阶段清理、单点不移动、来源门禁与资源释放；工程检查和浏览器结果在完成后记录。

## 接线与验证方法

- `JourneyTrack` 区分 `sourced_deployment` 与既有方向证据，单点仅允许 garrison/pressure；方向必须有两个以上来源点。展示窗口与动作窗口结构校验不通过时拒绝加载。
- 主地图使用蓝色立体盾牌表示守备、蓝色棱锥表示压力，追击/增援使用现有细长箭头及虚线。高度来自同一地形采样；不新建 Canvas、RAF 或历史时钟。
- “地图工具 → 地图图层 → 国军图层”同时控制新旧蓝方线条、图形和标签。红军开关也真实控制行军层。默认观察仍是红军，不因增加敌军而自动抢镜。
- 标签显示具体部队与动作，日期置于提示中，复用逐帧投影及实测尺寸避让。回退时仅复原曾被改写的蓝线端点，避免逐帧遍历整条路线。
- 新回归覆盖真实 Three.js 对象、单点不动/不连线、动作窗口、暂停/回退、开关与 React 接线、原始审核不变、资源释放。原四渡蓝线与连续讲述断言保留。

## 验收边界

本轮 Windows Computer Use 再次因无法可靠识别当前浏览器网址而终止。已停止电脑控制，没有绕过限制，也没有本轮 GPU 实机截图；工程测试不能代替实际视觉验收。刷新本机4192生产预览后可在主地图查收。原生后台隐藏专项仍未验证。

新来源全部 draft/unpublished，未新增真人审核、未变更 B 原始 dataset。尚缺可定位证据的独立分支、部分非战斗章节没有强行补充敌军轨迹；目前是有来源的战略态势展示，不是全长征逐时、逐部队道路复原。

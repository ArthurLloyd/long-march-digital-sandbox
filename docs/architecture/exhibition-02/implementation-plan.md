# C-EXHIBITION-02 实施方案

基线：7b7e2c282591b3220ef00a78fc2980e314f9557a。origin/main：10e9ce7240816f51840902e4cba4936666d02a81。原工作区与已运行4188预览保留；新分支 feat/exhibition-journey-integration。

用户已经批准产品结构与实施顺序，本方案直接实施，无额外设计确认门禁。

## 结构

1. 原首页、Header、SceneViewport、连续全景渲染器和A公共 RegionalObservation 继续复用。正常主站采用整理后的展馆组合；原App严格数据/注入模块入口保留供已有契约消费者与C1回归。
2. 地理Region保持八区，浏览状态独立于Chapter和C2 phaseId。全局只显示分区，瑞金开篇保留火炬；会师等具体事件按用户最新反馈收回区域或章节；明确选择区域后展开事件，缩放不触发产品区域跳转。
3. 事件落点继续使用C独立展陈层，正文引用B原对象。新增史料作为独立C补充资源，用已有v2事件、来源、人物契约校验；保持draft/unpublished，不改B既有字段/记录。
4. C2 usePhaseClock增加可选连续transport扩展。正常展馆启用连续演示时间，旧四秒步进只用于原严格消费者，两种调度互斥。章节/阶段由同一个transport派生，UI与renderer订阅同一状态；不引入另一个可同时播放的时钟。
5. 有来源的地名行动次序采用战略示意路段，显式schematic/高位观察；没有道路依据时不做真实道路低空穿行。没有区间依据时章节转场，不连事件点补路。
6. 故事只保留中央dialog；来源、操作说明分别按需打开。姓名由personId白名单分词渲染成按钮，悬浮卡保持在dialog内，以弹窗内absolute定位避开正文滚动裁切，先Esc关人物再关故事；无innerHTML替换。
7. A资源仅通过公共出口加载。C控制single/continuous范围，保存入口前的序列、时间、部队、区域、事件、视角、相机、播放和来源；退出保持暂停，不修改C1完成条件。
8. 安全区同时供标签避让和镜头构图使用。固定四地图按钮独立于工具面板，底部不放长正文。

## 实施与验证

A 结构与遮挡 → B 中央故事/人物/新增出发会师资料 → C A体验范围/恢复 → D 四渡赤水有来源箭头与三镜头 → E 扩展可用章节、回归、三种桌面浏览器证据与性能。

各阶段记录实际提交，最终完整工程检查、独立Draft PR与 phase-exhibition-02-report.md；不合并、不部署。

## 取舍

沿用旧App直接继续堆条件会继续混合三套阅读状态；重写地图会丢失已验收地形。选择保留原渲染与公共业务模块，收敛正常展馆组合，并让旧strict入口保留原契约行为。新增组合不增加页面路由，也不复制Three.js实现。

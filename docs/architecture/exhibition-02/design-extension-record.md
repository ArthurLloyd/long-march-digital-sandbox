# C-EXHIBITION-02 设计扩展记录

记录日期：2026-11-03。依据为[实施方案](implementation-plan.md)、当前展馆源码、既有 `PRODUCT.md` / `DESIGN.md` / `.impeccable/design.json`，以及下列实际浏览器截图。本轮属于现有展馆的普通扩展，沿用“山河之间，信念长明”的视觉身份；没有另立视觉世界，也没有获批的栅格设计稿可供逐像素比对。

本记录只描述 C 的展馆组合、阅读层和地图包装层。A 的原始场景与 B 的原始史料文件不在这次设计扩展的修改范围内。设计检查不能代替史料双人复核、素材授权或地图合规核查。

## 保留的设计身份

- **色彩关系。** 墨蓝页面、蓝黑阅读表面与暖纸文字仍为主体；浅金承担标题、边框、标签与焦点，朱红承担开始、播放及选中反馈。延续既有 CSS 变量，没有把现代地形的绿色和土黄色提升为界面品牌色。
- **字体角色。** 瑞金开篇与短句继续使用既有行书，阅读标题采用宋体，正文和操作采用黑体。首页手迹图形、品牌火种印章和既有红金角饰继续复用；没有新增人物手迹或历史徽章的真实性主张。
- **构图与深度。** 地图继续占据主视野，顶部品牌与导航、右上地图工具、底部回放控制保持明确的边缘位置。正文使用平整深色表面、细金线和分隔层级；背景雾与地形不进入正文。人物卡的局部阴影用于区分叠层，未扩展为通用卡片系统。
- **既有模块。** 首页、进入确认、Header、SceneViewport、连续全景地图及 A 的公共区域观察入口继续复用。没有重绘地图来替换已集成的地形，也没有通过本记录改写公共设计 token。

## 本轮组件与布局扩展

| 扩展               | 已实现的表现与边界                                                                                                                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 瑞金开篇           | 左侧保留行书叙事、红金“开始行军”与较轻的自由探索入口；场景保留火炬。开篇与自由全局是不同浏览状态。                                                                                         |
| 全局八区标签       | 全局只展示八个区域入口；区域标签使用固定屏幕偏移、避让布局与细金引线，地理锚点不随标签偏移而改变。明确选择区域后才展开该区域事件，普通缩放不触发产品区域切换。                             |
| 统一行军控制       | 底部集中播放、前后章节、重启、进度、序列、章节、倍速、观察部队与俯瞰／随行／自由镜头。UI 和渲染器读取同一 transport；演示进度不表示历史时长。                                              |
| 固定地图操作       | 全景、俯瞰、放大、缩小四个按钮独立于“地图工具”收纳面板，减少操作时打开侧栏的需要。地图标签与相机构图共享界面安全区。                                                                       |
| 中央故事窗         | 故事复用模态容器，改为居中的单一阅读表面；日期／地点、可滚动正文和底部来源／返回操作分层。最大宽度为 940px，保留视口边距；正文为 17px、双倍行高，最长约 70ch。来源与操作说明按需另开。     |
| 人物卡             | 正文中的登记姓名作为按钮，支持悬停、键盘聚焦、点击固定、切换与关闭。卡片在故事窗内绝对定位并限制宽高，避开正文滚动裁切；照片失败时退回文字。肖像与出处取自已有数据关系，没有新增合成人像。 |
| 到达提示与体验返回 | 事件到达时暂停演示，显示可立即点击的到达提示，三秒后打开正文。单区／连续区域观察沿用 A 的公共出口；返回恢复已保存的地图上下文并保持暂停，未改变 C1 完成条件。                              |

桌面控制栏常态高 142px，短屏高 126px；宽度至多 1500px 时收紧列宽与间距，视口高度至多 820px 时收紧控制栏和阅读留白。这些是本轮桌面适配，不能外推为已验收的手机方案。

## 动效与可访问性

故事窗以轻微上移和显现进入（240ms）；开始按钮沿用短暂的悬停位移与颜色反馈（180ms）。到达提示及相应事件标记在等待阅读时使用亮度呼吸（1.15s），不是历史事件持续时间。减少动态偏好关闭该呼吸、故事窗入场及开始按钮过渡；地图创建时也读取该偏好。静态截图不能证明连续动画、镜头舒适度或动态性能已通过。

源码保留以下操作支持：故事窗声明 `dialog`、`aria-modal` 与标题关联，打开时聚焦标题、约束 Tab、锁定页面滚动，关闭后恢复触发点；人物卡有可见关闭入口，Esc 优先关闭人物卡并恢复姓名焦点，随后才关闭故事。镜头按钮使用 `aria-pressed`，进度、倍速、章节与部队控件有可访问名称；展馆可见焦点使用浅金轮廓（2px，外偏移 4px）。

这些是源码层面的实现记录。所查截图没有覆盖屏幕阅读器、完整键盘遍历、真机触摸或色彩对比度专项测试；不能据此宣称全部无障碍要求已验收。局部控件仍有 32–42px 高度及 11–13px 辅助字，未将其登记为新的全局点击面积或正文标准。

## 追加：区间行军与阅读清理

用户要求将于都之后及全部主线区域变化统一为全景→俯视虚线与动态箭头→近景到达。现用同一C2进度派生三个相机阶段，新增虚线预览层与已走过的亮线，箭头采用较窄长尾、尾端收尖。相机与观察目标同步移动，开始/继续恢复随行；原4倍速度成为显示1倍的基准。

新增的限定代码复审确认单时钟、序列过滤、到达清理与资源释放未见新阻断；发现跨区阶段缺少持续示意文案，修复为“跨区战略示意 · 非历史道路”后复核通过。该复核不是连续镜头或帧率批准。B的正文在C阅读层整理为自然叙述，原编审说明和原文来源保留在来源页面。

## 追加：两套行军镜头

俯瞰收近为区域取景，并为箭头提供中央半屏的静止区；箭头进入外侧四分之一后才触发平移。随行改为斜侧方近景，使用较小的98顶点贴地箭头，保持显示间距随山坡弯曲。俯瞰采用较大平直悬浮箭头，两者不共用强制跟随策略。名称标签移到箭头旁边，暂停继续保留用户选中的俯瞰模式；地图容器不再因底部控件聚焦产生内部滚动。

本次较近的视角增加了地形遮挡敏感度，因此只提升镜头越过中间山脊，保持水平距离；未新增路径顶点、历史定位或场景素材。见[追加验收](../phase-exhibition-02-report.md)。

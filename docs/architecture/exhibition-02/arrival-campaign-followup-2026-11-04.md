## 接入远端 A 最新成果

本轮开始时本地为 `8fb55a843e0d78def6feb56e4f403f48d94c2117`；检查远端发现集成分支已经有 [#26](https://github.com/ArthurLloyd/long-march-digital-sandbox/pull/26)、[#27](https://github.com/ArthurLloyd/long-march-digital-sandbox/pull/27)，远端头为 `625f774ac13f4747123e755cb3a0197bf82e04dd`。这两个 PR 已经由远端工作进入当前集成分支，不是本轮执行的 PR 合并。

先提交本地 C 修正 `49b15f4` 保护工作，再普通合并远端头。只有 `ExhibitionJourney.tsx` 的 import 区冲突，保留两方组件并按章节选择一种面板。A 的四渡区域沙盘、蓝方宽线、地点区分、扎西讲解、六章连续播放策略和全部新增测试保留；本轮未更改 A 专属实现。新增世界地图战略轨道共37条，其中蓝方11条，来源是 A 的新交付，本轮没有另造军事经纬度。

四渡六章沿用远端 `pauseAtArrival=false` 与主动阅读机制，避免战况讲解被1%停靠打断；金沙江及之后保持到达停靠和三秒资料卡机制。两种展示策略共用同一 C2 时间源。

切换“自由”会取消尚未结束的相机飞行及旧异步取景回调，同时保留地形准备，避免地区加载稍后完成时把用户镜头拉回；真实渲染器边界测试与应用接线测试均覆盖此情形。

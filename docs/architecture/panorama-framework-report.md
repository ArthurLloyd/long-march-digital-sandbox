## 复用与架构边界

本轮复用 C2 的 `usePhaseClock` 状态机内核；正式接线仍以 `useHistoricalPhase`、`scene-phase-view` 和 `force-state` 为阶段及态势输入，不另设正式历史时钟。C1 的体验运行与完成机制保留，原型不写完成记录。

地图按现代地理、现代河流、区域入口、历史路线、部队态势与界面标签分层。`PanoramaMapAdapter` 提供区域取景、总览、缩放、书签恢复、路线输入、暂停与释放；A 后续通过 `src/features/scene/index.ts` 的公共出口接入，不反向依赖 app。`CinematicTitle` 复用项目已采用的志莽行书；题字出现时收起标志和资料，地图展开，点击题字或左侧同一事件后恢复资料，底部阶段栏继续可用。

原型位于 C 的 `src/app/panorama/`，通过仅开发服务提供的入口读取原始候选内容。正式构建检查实际模块引用，拒绝 `fixtures`、测试入口和 `src/app/panorama/`，生产预览的 `/__dev/panorama` 为 404。后续正式接线须明确拆开候选调试与可发布渲染，再调整隔离门禁。

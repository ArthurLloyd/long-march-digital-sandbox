## 最终实现与模块边界

`App` 通过 lazy 加载 `src/app/landscape/ExhibitionPanorama.tsx` 作为默认宏观场景，接受既有 `LongMarchSceneV2Props`。首页、主动进入确认、加载／异常／重试容器、原导航与抽屉继续由原应用管理。公共题字位于 `src/components/exhibition/CinematicTitle.tsx`，样式位于 `src/styles/event-cinematic.css`；原型与生产共用视觉能力，不共用候选 UI。

现代地理、地形网格、水体、材质、镜头与来源资产已抽到 `src/app/landscape/`。`map-regions.ts` 的八个名称是现代山河取景；选择它们只改变视野和题字，不切换正式历史阶段，也不调用 C1。正式事件、路线与部队态势只消费 App 已验证、已发布、经 `selectScenePhaseView` 投影后的当前阶段输入，不重新把投影视图当完整数据集校验，更不从未知位置推导路线。

C2 的 `useHistoricalPhase` 仍是正式阶段状态源；开发目录只复用同一时钟内核。C1 的 runId、首次介绍、主动完成、存储、重播、退出及上下文恢复保留。地图首帧反馈是宏观场景 ready，与沉浸体验 ready 分离；主动“阅读事件”前即时保存当前镜头书签，避免用过期位置恢复。scene-local 书签不表示历史经纬度。

候选原型仍在 `src/app/panorama/`：十一段浏览目录、候选正文、四渡非地理板、三个占位入口和开发兼容出口都在此范围。生产模块门禁继续拒绝该目录、测试入口及 fixtures，生产预览拒绝 `/__dev/`、`/src/` 等开发访问。

## 发布隔离与来源安全

`scripts/history-release.ts` 的 `virtual:history-release` 在构建时派生正式快照。App 获得发布过滤后的数据及只含 ID／阶段模式信息的限制：撤回或缺失依赖只能拒绝访问，不能据此解锁候选内容。原始候选 JSON、正文和人工审核记录保持原样。

生产构建关闭 `publicDir` 自动复制，只输出展馆必要文件和已发布素材的明确允许清单；同时检查实际代码模块、未许可素材字节哈希、候选正文／材料标识及最终输出目录。生产预览保留同一访问边界。此门禁阻止候选内容随地图融合泄漏，不授予史料、字体或图片新的使用权，也不替代两名不同成员的独立复核。本轮没有整包合并 #15。

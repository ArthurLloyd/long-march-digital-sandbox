# 原创白模军队素材

- `clay-marcher.glb`：可编辑单人物，帽子、背包、铺盖、绑腿与靴子；含 1 秒循环 March 动画。
- `marching-company.glb`：18 人静态编队与无标记红旗；可编辑层级。沿桥移动由 Three.js 时间轴驱动，不含路线动画。
- `bridge-cover.jpg`：本工程实际 Three.js 渲染截图。
- `manifest.json`：模型字节数与 SHA-256。

原创程序几何，无外部模型复制。人物、制服细节与编队规模为艺术示意，不能当作历史考证。作者源与导出器分别位于 `src/features/scene/prototype/marching-company.ts` 和 `src/features/scene/sandbox/tools/export-scene-kit.ts`；授权沿用本项目约定，未额外授予第三方素材权利。

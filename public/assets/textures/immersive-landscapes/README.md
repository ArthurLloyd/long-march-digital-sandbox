# 山河行迹 · 沉浸环境素材

2026-11-02 在用户安装并登录的 **MiniMax Design 4.0.6** 中实际生成，使用 **Design Image 2.5 Pro**。项目名为“长征-山河行迹-沉浸素材”。这是 AI 环境概念设计，不是历史实景、测绘资料或视频。

| 素材              | 主题                       | 当前采用版本                   |
| ----------------- | -------------------------- | ------------------------------ |
| river-valley.webp | 山河之间：峡谷、水脉、晨光 | MiniMax 第二轮候选             |
| snow-pass.webp    | 雪岭微光：雪脊、云海、远山 | 首轮原图，后续候选背面衔接更差 |
| grassland.webp    | 草地回声：湿地、草甸、天际 | 首轮原图，后续候选背面衔接更差 |

三张模型原生图均为 **3840×1920**，不是 4096×2048。仓库中的 WebP 保留原生尺寸，quality=90；`*-cover.webp` 是 MiniMax 从首轮场景导出的导航封面，缩至 1280×720。原始 PNG、第二轮候选、接缝居中待修图保留在本机 MiniMax 项目 assets 目录。`manifest.json` 保存来源文件名、SHA256、模型、尺寸、状态与局限。

## 当前质量状态

- 三场景均已在真实 Three.js 球面中检查正面与背面，支持交互预览。
- **无缝验收未通过。** 2:1 生成结果不等于完美球面全景，背面仍有接缝和空间连续性问题；不得称为正式无缝成片。
- 已完成 3 次首轮生成和 3 次修订。下一轮采用“水平循环位移半幅 → 中央窄带重绘 → 位移还原”，其待修图已保存，但 MiniMax 提示需要 410 积分、账户剩余 277；该生成已停止，没有充值。
- 未生成 AI 视频、对白、战斗、人物或真实历史路线。三个环境不绑定本区域地图中的虚构历史坐标。
- 正式节点需要在 B 的候选脚本审阅后完成内容对应、无缝精修及媒体审核。当前目录标题与短句是环境引导文案，不是史料陈述。

## 接入与复查

开发入口 `/src/features/scene/sandbox/index.html` → “走进山河”。

可用 `?inspect` 打开“查看接缝”检查按钮；普通体验隐藏此开发控件。全景默认不自动旋转，按需重绘，切换纹理与退出时释放 GPU 资源。渲染代码属于 A 的 scene 范围；没有把 MiniMax 自动生成的未验证 HTML 直接写入正式 App。

借鉴教程的“地图 → 可环顾场景 → 返回地图”结构；不复制教程作者的图片或模型。实际浏览器证据与测试见 `src/features/scene/sandbox/ACCEPTANCE.md`。

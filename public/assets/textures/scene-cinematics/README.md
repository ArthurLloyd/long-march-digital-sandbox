## 新片声音处理

已交付的 V2 保留片及修正版保留原视频流，只处理 MiniMax 原生音轨：55 Hz 高通、轻度动态压缩、末 0.4 秒淡出，再做两遍响度归一化，输出 48 kHz 立体声 AAC。目标为 -18 LUFS、真峰值 -2 dBTP；机器交付门槛为综合响度 -19 至 -17 LUFS、真峰值不高于 -1.5 dBTP。没有加入下载的或另行合成的声音，不裁剪原视频；仅清除音频解码/归一化产生的尾部填充，使音轨与视频时长对齐。

八条选定成片均有完整解码与音频门槛通过记录。逐条实测值见 provenance；人工试听字段明确记录 `subjective_listening_not_performed; encoded_audio_and_loudness_verified`，仅确认编码音轨与响度，不宣称人工听感验收。八区实际入口与自然结束切换已完成浏览器简查；除遵义的短片状态读取时已自然结束外，其余七条均直接读取到正确新片路径、可播放状态和未静音状态，遵义已观察到影片层并正常到达对应三维场景。

播放器默认音量为 0.9；用户调整过的音量和静音选择在当前页面会话内保留，重看或跨区不会强制恢复默认值。

## 素材性质

影片为 AI 艺术再现：匿名代表性人物和概念环境，不是史料影像、实测地形、制服考证或具体战役过程复原。影片不内嵌标题和字幕；网页角落保留小号艺术再现标识。原片由用户 MiniMax 项目保留，不改动原文件；使用条件仍以该账户适用的 MiniMax 条款为准，没有将其写成开源素材或独占版权授权。

## 接入行为

同一个 `RegionalObservation` 对话框在每次进入已启用区域时先显示不透明影片层，并暂停、隔离下层三维交互；场景可在后台预热，但不会先露出近景白模。影片正常结束后 480 ms 淡入到开阔三维视角。影片不循环，重看仍回到同一空间；仅加载当前进入区域的影片，不提前加载全部八条。

音量、暂停、重看和返回总图由本地界面提供，不在影片上铺大标题或 HUD。浏览器限制有声自动播放时显示明确播放按钮，不把拒绝播放当成成功；加载出错可继续探索。减少动态偏好允许直接进入场景。切到后台会暂停播放；跨区、返回总图或卸载时暂停并释放视频源，清除定时器和事件监听，避免串片或退出后仍出声。

本轮只接入自由观察入口，正式 C1 段落调度、B 审核内容、历史时钟与完成计数均保持原契约。八区启用是媒体选择与本地集成状态，不表示正式历史体验已完成。

这里的“交互”是入口、播放控制和影片到三维的衔接，影片本身是线性情境短片，不宣称分支剧情或 360 度视频。
